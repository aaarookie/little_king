# v0.8.3 法术与天使增援协作记录

更新：2026-10-02。本文记录本轮需求、代码职责、初版数值和验收状态，供其他协作者接续。素材来源见 [54](54-v0.8.3Assets.md)，UE 5.8 试玩入口见 [55](55-v0.8.3Guide.md)，最终验收证据见 [56](56-v0.8.3ReleaseNotes.md)。

## 本轮范围和确认规则

新增九张法术卡、十一种召唤单位。所有新法术都需要在家园图书馆消耗对应法术书研究，不自动加入新存档解锁列表，也不作为远征奖励直接发放。天使只有战场单位定义，没有独立单位卡牌，只能由四种圣玛丽亚增援法术召唤。

用户已确认：雷电只攻击敌方非英雄，按当前生命值排序；神圣祝福只治疗己方。黑云是影响双方的动态区域，进入后隐藏、离开后恢复可发现。飓风只推移双方可移动角色，建筑和英雄营地保持固定。

牧师的基础行动为远程治疗受伤友军，这属于职业行为，不添加技能或特性。失能英雄仍不能被战斗内治疗救起。增援法术本身允许全场合法落点，不依赖法师存活或全场施法特性。

祝福的冷却从成功施放开始，以战斗时间计时，暂停时停止。下一场战斗从零冷却开始；冷却结束代表卡牌重新具备抽牌资格，仍按牌库循环顺序补入，不直接覆盖当前手牌。

## 解锁和研究材料

市场继续采用每节点 1% 概率生成一本法术书、达到区域深度 1 后 0.5% 概率生成建筑图纸。新增书籍参与既有抽取池，不额外提高总掉落率。区域深度从零开始，只有达到门槛的书籍才参加加权抽取；权重不是单本书的直接出现概率。

本轮修正市场代码对研究目录“最后一行是建筑图纸”的依赖。图纸现在按材料种类和进度门槛筛选，新增法术放在目录尾部也不会使图纸商品变成法术书。

## 远征升级和调参接口

法术只能在休息节点升级，倍率仍是 `1.1^本轮等级`。本轮按各效果指定调整数值：冰冻增加冻结时间；黑云增加区域持续时间；雷电增加第一击伤害上限和第二击伤害，20% 比例与 0.2 秒延迟不变；飓风只增加推移速度；增援只增加召唤单位的最大生命和攻击／治疗；神圣祝福只增加英雄恢复比例并封顶 100%。范围、银币费用、召唤数量、攻击间隔和祝福 150 秒冷却均不因休息升级而改变。

`ULKCardDefinition` 新增持续时间、矩形半尺寸、推移速度、抽牌冷却、全场放置许可和召唤单位 ID 列表。雷电的最大生命伤害比例、第二击伤害及延迟也有独立字段，数值调整不需要复制一份新施法逻辑。法术种类、召唤身份、阶位和永久研究资格由内容代码保持稳定，作者配置保留费用、范围和效果数值。

## 验收状态

UE 5.8.1 / Win64 Development Editor 构建成功。全量 `LittleKing` 129 项通过，0 失败，包含二十项新增专项；其中 64 项无警告，65 项带测试环境或预期拒绝路径警告。警告和原始日志路径在 [56](56-v0.8.3ReleaseNotes.md) 逐项说明，不把带警告通过写成无警告通过。

专项覆盖法师失能后的敌方半场增援、召唤失败费用和手牌回退、黑云内外与重叠索敌、雷电延迟重新排序、飓风碰撞与固定建筑、牧师目标和弹道、祝福不复活以及 150 秒冷却／补满过牌。飓风另通过引擎真实世界 Tick 验证冻结敌人当帧向右且保持冻结姿态、离开区域恢复自主移动。

720p 与 1080p 各生成 28 张素材／步态／法术截图和一张原生 UMG 冷却图，共 58 张。五图集 80 个姿态、九卡图和六 WAV 的来源字节、完整提示词、透明度、帧边界、声道、采样率与峰值审计通过；125 个 UE 资源均已导入。六个既有存档 SHA-256 保持不变。

声音主观听感、新法术的长期远征平衡留给实际试玩反馈；本轮没有进行打包或设备验收。无需手工补代码、蓝图或下载资源；[55](55-v0.8.3Guide.md) 提供不影响现有存档的九法术试玩与试听入口。
