# v0.8.3 · 法术与天使增援

开发验收：2026-10-02；发布：2026-10-03，`main` / 注释标签 `v0.8.3`。本页合并本版变更与发布记录，数字为**v0.8.3 历史结果**。当前玩法与数值见 [01 GDD](01-GDD.md)、[19 图鉴](19-ContentCatalog.md)，扩展契约见 [34 开发接口](34-CardDevelopmentInterfaces.md)，素材来源与生成记录见 [36 来源台账](36-ArtAudioSources.md)。

## 阶段结果

新增九张研究法术和十一种仅由法术召唤的天使配置；旧档不自动解锁，已有市场不重抽。冰冻复用冻结接口；四档圣玛丽亚增援支持全场合法落点，整组生成前校验位置与单位上限，失败保留费用和手牌。天使牧师使用治疗普攻。

黑云按来源动态管理双方隐藏与发现；雷电两击分别按当时的当前生命选择敌方非英雄；飓风逐步推动双方可移动角色并尊重碰撞/边界，冻结者保持冻结姿态。神圣祝福只治疗己方，不救起失能者；成功施放后的 150 秒抽牌冷却随暂停停止，每场重置，过牌仍保持四张唯一满手。

研究、战备和休息升级完整接入，效果参数集中在卡牌定义。原生界面补充矩形/全场预览、隐藏/受风状态、治疗弹道和祝福倒计时；修正长增援名称字号与强制位移当帧朝向。新增五图集、九卡图和六条合成声音，共 125 个 UE 资源；声音注册保留显式静音与自定义覆盖。
