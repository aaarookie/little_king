# 阶段三新角色、品质与卡组：UE 5.8 新手教程

更新：2026-09-17。设计与完整数值见 [32](32-CharacterQualityAndBalance.md)，全内容图鉴见 [19](19-ContentCatalog.md)，协作改动见 [29](29-OptimizationChangeLog.md)。本页已同步最新加权容量与多选替换；七张巨魔/攻城扩展卡的数值、控制规则和生成命令见 [35](35-TrollAndSiegeCards.md)，开发接口见 [34](34-CardDevelopmentInterfaces.md)。

本阶段的 C++、原生奖励/替换 UI、已有手牌 UI 兼容接入已经制作。**没有必须由你补建的蓝图、数据表行、卡牌资产或美术资源**。下文用于启动、试玩与后续自行调数值；正式美术、音效、打包及硬件验收继续后置。

## 1. 启动更新后的项目

1. 先停止 Play，关闭 Unreal 编辑器。此次新增了反射枚举、结构体字段和组件，完整编译比运行中 Live Coding 更合适。
2. 打开 PowerShell，执行：

   ```powershell
   & 'E:\epic\UE_5.8\Engine\Build\BatchFiles\Build.bat' little_kingEditor Win64 Development '-Project=E:\little_hero\little_king\little_king.uproject' -WaitMutex -NoHotReloadFromIDE
   ```

3. 看到 `Result: Succeeded` 后打开 `little_king.uproject`。如果工程或引擎放在别处，替换命令中的对应路径即可。
4. 点击 Play，从开始界面进入一个存档，在家园大门出征。想单独试验新角色，可用一个新存档；已有存档仍可继续。

新卡由运行时内容目录自动创建，因此在内容浏览器中搜索 `Unit_ElfArcher` **不一定有同名资产**。这不是缺资源：游戏用稳定 ID 读取原生定义，并正常生成卡牌与单位。

## 2. 品质、法术等级和满额替换

- 手牌显示“名称 / 品质或法术等级 / 银币费用与占格”；鼠标停留可查看基础数值与技能。颜色为白、绿、蓝、紫、橙，同时保留中文品质名称。
- 家园军营、图书馆、战备与大门详情也显示分类。15 张远征临时卡（含攻城建筑）不会出现在家园永久解锁列表中。
- 每次非终点战斗胜利，从三项奖励中选一项。新卡候选由种子随机生成，15 张临时卡与两张骷髅卡共用候选池；不保证每次都出现指定角色。较高奖励档可提供更多新卡候选，已有卡不会重复出现。
- 初始牌组仍默认七张。规则为最多 **8 格容量**且至少五种不同卡牌：四种巨魔各占 2 格，擎天巨像占 3 格，其他卡各占 1 格。当前永久解锁只有原七张，因此家园暂时不会凭空出现第八种永久卡。
- 获取新卡后不超过 8 格时直接加入；超过时出现两列旧卡列表。勾选一张或多张旧卡，核对释放容量、替换后容量和张数，再点击“确认替换”。确认前不会丢卡；被替换卡的本轮强化不转移，新卡从 Lv0 开始。
- “返回奖励选择”取消替换选择，原卡和奖励保持不变；回到奖励页后仍可选另一项或跳过。滚轮可阅读奖励卡的长技能说明。
- 三位英雄不占这八格容量，战场单位数量上限也保持原规则。多格卡抽到时仍占一个手牌槽；四个手牌槽始终补满，同类卡不会同时出现两张。

奖励与替换界面使用原生 UMG，不需要在 `WBP_BattleHUD` 中手工连接新的按钮。旧 `CardSlot_0`～`CardSlot_3` 会自动更新名称、分类、费用、文字大小和提示。

## 3. 不等随机奖励，直接试角色

进入一场战斗，先放完三个英雄并开始。按键盘左上角的 `~`（通常在 Esc 下方）打开控制台；也可打开“工具 → 调试 → 输出日志”，在底部控制台输入命令。

`SpawnUnit 单位ID 阵营 X Y` 只生成战场单位，不会永久解锁、增加卡组或扣银币。阵营 `0` 是玩家，`1` 是敌方。玩家位置使用负 Y，敌人使用正 Y；位置被其他实体占用时换一个空位。

```text
SpawnUnit Unit_ElfArcher 0 -700 -500
SpawnUnit Unit_ElfWarrior 0 -400 -500
SpawnUnit Unit_ElfGuard 0 -100 -500
SpawnUnit Unit_ElfPriest 0 200 -500
SpawnUnit Unit_GoblinRogue 0 500 -500
SpawnUnit Unit_Thief 0 800 -500
SpawnUnit Unit_ApprenticeMage 0 -500 -800
SpawnUnit Unit_GoblinBlade 0 500 -800
```

建议分批试，不必一次塞满战场。`ListUnits` 查看实际生成的单位；`ListRunState` 查看远征状态；`AddSilver 10` 增加战斗银币（仍受上限约束）。这些银币与 `show me the money` 添加的家园金币是两种资源。

## 4. 建议的人工观察步骤

| 内容 | 操作 | 应观察到的结果 |
| --- | --- | --- |
| 三种精灵回血 | 生成一种精灵，用 `DamageUnit Unit_ElfArcher 0 30` 等命令扣一点生命，再让其普攻命中 | 弓箭手/战士/盾卫分别回最大生命 3%/4%/5%；远程弹丸命中时才回，技能伤害不触发 |
| 共沐春色 | 留一名牧师，让英雄受伤，再让精灵攻击回血或受到治疗 | 生命比例最低的存活英雄收到精灵实际治疗量的等量治疗；溢出治疗不计，失能英雄不被救起 |
| 背刺 | 场上留多个敌人，观察大盗战斗满 8 秒后的施放 | 选最远敌人、在其身后落地、300% 攻击伤害并持续锁定；目标死亡后很快再次背刺 |
| 嘲讽免疫 | 让敌方盾卫靠近大盗，再观察背刺锁定目标 | 大盗不因嘲讽换目标，其他普通角色仍遵守原嘲讽优先级 |
| 战利品 | 让窃贼攻击一个目标，其他友军也攻击该目标 | 目标死亡后加 1 银币，无须窃贼补最后一击；满银币时不突破上限 |
| 模仿施法 | 带着初阶火球/治疗波出征并部署学徒，等待 10 秒 | 随机施放完整卡组中的初阶法术，不限四张手牌；没有符合项时使用初阶火球；不扣费、不轮换手牌 |
| 让开！ | 将利刃放在敌人一侧，前方附近放一座建筑，等待 5 秒 | 冲刺经过的敌人各受一次 200% 攻击伤害并向两侧退；建筑受伤但不移动，冲刺被实体/边界阻挡 |
| 临时性 | 获得新卡后暂回家园再继续；最后结束远征 | 暂回与读档保留本轮卡组，真正结束远征后不加入家园解锁；下轮重新使用已保存战备 |

原生主动技能从参战开始计算首次完整冷却，部署阶段不会自行计时。大盗的窃取是 30% 随机事件，连续几次没有获得银币属于可能结果；只有火球类施放产生现有小震动。

精灵牧师的最低生命比例选择可能随着每次治疗改变。多位牧师各结算一次，但“复制来的治疗”不再次触发共沐春色。

## 5. 调整数值（可选，不是接入前置任务）

### 修改单位基础数值

1. 在内容浏览器打开 `/Game/Data/DT_Units`。
2. 新单位没有表行时仍能游玩；想开始调参，再新增与 [32](32-CharacterQualityAndBalance.md) 完全一致的行名，例如 `Unit_ElfArcher`。
3. 参照文档表格填 `BaseHealth`、`AttackDamage`、`AttackInterval`、`AttackRange`、`MoveSpeed`。用 `AttackWindup = 0.15`；不需要美术时清空 `Sprite`。
4. 主动佣兵可调 `SkillCooldown`。背刺的 `SkillDamageMultiplier = 3`、`SkillSilverChance = 0.3`；利刃的倍率为 2、距离 450、速度 1800、命中半径 100、击退距离 120。倍率填 3 表示 300%，概率填 0.3 表示 30%。
5. 保存数据表，停止并重新 Play。已在场 Actor 不会即时重读刚改的表；新房间或重新生成单位后观察结果。

内置角色的品质、种族、类别、攻击方式和技能类型由 C++ 注册表保证；修改这些表字段不会改变它们的身份。三种精灵固定回血百分比也是当前技能规则。要改变这些规则，应修改原生内容定义并重新编译，而不是复制一行后误以为改了身份。

### 修改新卡费用或替换图标

默认不需要制作卡牌资产。若希望协作者从编辑器调新卡费用：右键内容浏览器空白处 → 杂项（Miscellaneous）→ 数据资产（Data Asset）→ 选择 `LKCardDefinition`，填写与单位相同的 `CardId`，例如 `Unit_GoblinRogue`，设置 `Cost` 和 `Icon`，再加入实际使用的 `DA_GameData.CardLibrary`。运行时会保留费用和图标，自动补回名称、生成单位、临时标记和技能说明。

现有法术资产新增 `SpellGrade` 下拉选项，共 14 档。当前火球和治疗波都是“初阶一级”。修改等级不会自动乘伤害；效果大小仍由 `SpellValue`、`SpellRadius` 决定。学徒只选择初阶一级～三级。

## 6. 旧存档与协作约定

远征契约升级到 Schema 8，Schema 6/7 的路线、种子、钱包、英雄状态原样保留。若旧远征按占格计算超过 8 格，界面先要求手动移除多出的卡牌；读档本身不会自动删除卡牌，裁减仍须保留至少五种卡。选择保留的卡牌，其原有强化等级继续保留。领卡、替换、跳过或裁减若保存失败，内存中的原卡和待领取奖励保持原状，可重试。

本轮不修改已发布版本标签。源码入口：`LKExpeditionMercenaryContent` 管内容与初版数值，`LKCardPresentation` 管文字和分类色，`ULKUnitActiveComponent` 管冷却主动技能，`ULKUnitPassiveComponent` 管回血/共沐春色/战利品，`ULKUnitStatusComponent` 管控制/强化/点燃/巨魔支援，`LKCardRules` 管容量预算，`ULKRunRewardWidget` 管奖励和替换，`ULKRunSubsystem` 管持久化事务。
