# v0.8.2 · 远征研究、休息与暂停教程（UE 5.8）

本轮界面、原生卡牌定义和治疗波资产由工程直接提供，无须手动创建 Widget Blueprint、下载素材或补建数据行。缺少独立图片的新研究法术沿用项目已有火球／治疗图标，保持绘本风格。

## 开始试玩

1. 关闭此项目的编辑器，使用 UE 5.8 打开 `little_king.uproject`。代码有变更时先构建 `little_kingEditor / Win64 / Development`。
2. 点击 Play，进入开始界面。选择新的游戏或读取存档；进行中的远征会直接恢复远征界面。
3. 在家园点击战备处，编入三名英雄及至少七种不同卡牌。默认容量上限八格，临时巨魔占两格、巨像占三格，英雄不占格。四槽战斗手牌仍然每卡显示一张。
4. 在大门检查英雄、卡组与携带金币，然后出发。金库决定本金携带上限，远征收入不受此上限限制。

旧的五／六张战备仍可读取，但下一次出征需在战备处补至七张。进行中的旧远征保留自己的地图和战前快照，不会因更新重抽路线。

## 选路与暂停

每个新区域有十五层路线。分支使区域节点总数约三十至四十个，但实际只选每层一个：约九至十场战斗、两次市场和三次休息。只显示所在区域；区域出口可选择相邻区域的入口，进入后才展示其局部地图。

战斗或部署阶段，点击右上角“暂停 · Esc”或按 Esc：

- “继续”恢复计时、银币增长、单位、技能与增援。
- “退出游戏”保存并回到开始界面。这里不会关闭应用。继续该存档时回到本场部署之前；英雄生命、卡牌等级、敌阵和战斗随机种子与第一次进入相同。已选分支不能改选。

奖励、路线和服务节点可直接“退出游戏 · 保存远征”。如果要回家园，选择“放弃远征”，再点确认。战斗和部署期间不能放弃。通关或失败后也可返回家园。

## 获取与替换临时佣兵

胜利奖励可获得临时佣兵或升级已有佣兵；市场的普通商品也是临时佣兵。远征结束后这些新增佣兵及本轮等级消失，不进入家园永久收藏。

买入／领取超过固定容量时，界面要求勾选最少必要弃牌并确认。例如：

| 当前占格 / 新卡 / 上限 | 合法选择 |
|---|---|
| 7 / 2 / 8 | 弃一张一格卡 |
| 6 / 3 / 8 | 有一格卡时只能弃一格卡 |
| 8 / 2 / 8，持有两格卡 | 优先弃一张两格卡，同释放量无需弃两张一格卡 |
| 9 / 1 / 合法区间 8～10 | 不弃、弃一格、或弃两格均合法；包括两张一格卡 |

同一事务既加入新卡又移除旧卡，保存失败时二者都不变。远征过程中至少保留五种不同卡，确保四槽唯一循环能持续补牌。出征的七张要求与战内五种循环底线不同。

## 休息节点

本次休息任选一项：

- 全体玩家英雄增加 30% 最大生命，封顶满血。
- 选择已携带的一张法术或建筑，升级一等级。本轮效果数值乘以 `1.1^等级`：法术伤害／治疗增加，建筑生命／攻击增加。费用、范围、射程、间隔和机制不变。

升级不另收金币，但会使用本次休息机会，因此不能升级后再次回血。建筑／法术不再通过战斗奖励升级。等级仅本轮有效。右侧优先展示升级按钮；长列表和详情可用鼠标滚轮浏览，底部回血、退出与放弃按钮保持可见。

治疗波基础效果为范围内友军恢复 120 生命，英雄额外恢复 6% 最大生命；Lv1 合计乘 1.1。以基础满血上限计算，骑士恢复 480、法师 372、游侠 408。实际治疗被缺失生命封顶，失能英雄不能被战内治疗救起。

## 市场、材料与图书馆

市场通常有三种临时佣兵，每项只售一次。商品、售价、身份和售出状态随地图保存，不会因退出或读档刷新。

每个市场约 1% 概率出现一份法术书，约 0.5% 概率出现建筑图纸。图纸及中阶书从区域深度 1 开始，高阶书从深度 2、神阶书从深度 3 开始。这里的深度来自地理路线：西境 0、两个平行区域 1、关隘 2、王庭 3。同一书籍出现机会内，高阶的抽取权重更低。

| 研究内容 | 商品价格 | 解锁效果基础值（银币费用） |
|---|---:|---|
| 强化火球术 · 初阶二级 | 120 | 伤害 110，半径 250（2） |
| 烈焰火球 · 中阶一级 | 260 | 伤害 210，半径 280（3） |
| 灼日火球 · 高阶一级 | 480 | 伤害 380，半径 320（4） |
| 天火 · 神阶一级 | 800 | 伤害 650，半径 360（5） |
| 生命泉涌 · 中阶一级 | 260 | 治疗 160 + 英雄 9% 最大生命，半径 320（3） |
| 圣光潮汐 · 高阶一级 | 480 | 治疗 220 + 英雄 12%，半径 340（4） |
| 生命礼赞 · 神阶一级 | 800 | 治疗 300 + 英雄 16%，半径 380（5） |
| 攻城投石炮图纸 | 350 | 永久解锁已有攻城投石炮卡（4） |

这些是首版可研究内容，目录支持继续增加其他阶位和图纸。攻城投石炮已从远征临时建筑改为研究解锁建筑；旧轮里已持有的炮仍可继续使用。

买到书／图纸后不会马上出现可出牌卡。结束本轮远征后，点击家园图书馆，选择标有“待研究”的条目，再点击“研究 · 消耗一份材料”。成功后永久解锁，可到战备处编入后续远征；已解锁内容不能重复研究。研究本身不另外收费。

材料无论通关、失败还是主动放弃都全数带回；失败只扣金币，剩余钱包带回 80%，向下取整（101 → 80）。放弃带回 100%。已经用于购买的金币不退。

## 调整数值与协作接口

治疗波：内容浏览器打开 `Content/Data/C_HealWave`，搜索 `Spell Value`（120）与 `Hero Heal Percent`（0.06）。费用和范围仍在原资产中。代码兜底与资产基线需同步；`Scripts/ApplyV082.py` 是重置到本版基线的工具，不应用来保存自定义调整。

容量：`DA_GameData` 的 Expedition 分类设置 `Deck Capacity Minimum/Maximum`，默认 8/8 表示固定上限。8/10 表示替换后合法区间；新远征冻结这两个值。运行中的拓展事件可调用 `SetDeckCapacityRule`，随后奖励和市场立即使用新规则。

研究与市场：修改 `LKResearchContent.cpp` 的稳定 ID、价格、阶位、最早区域和抽取权重；机制继续使用现有范围伤害／治疗。增加图纸时应一并注册建筑原生定义。不要随意改已发布 ID，否则旧档材料将无法解析。

完整修改清单和测试证据见 [50](50-v0.8.2ExpeditionChanges.md)。本版不包含打包和硬件测试。
