# v0.8.3 开发与验收记录

发布：2026-10-03；开发验收：2026-10-02。工程版本为 `0.8.3`，版本标签为 `v0.8.3`，发布分支为 `main`。新增九张研究法术、十一种只能由法术召唤的天使单位配置，以及对应美术、音效和界面。代码职责和默认数值见 [53](53-v0.8.3Changes.md)，素材来源与十四次完整生成提示词见 [54](54-v0.8.3Assets.md)，UE 5.8 试玩及试听方法见 [55](55-v0.8.3Guide.md)。

## 已完成的内容

冰冻复用已有冻结接口。四档圣玛丽亚增援可全场召唤，生成前校验整组落点与单位上限，失败保留银币和手牌。牧师采用治疗普攻，不附加主动、被动或英雄特性。

黑云动态隐藏双方范围内单位，重叠场效按来源解除，攻击者重新索敌，地面法术仍可命中。雷电两击各自按当时的当前生命选择敌方非英雄。飓风分步推动双方可移动角色，尊重建筑、营地实体和战场边界；冻结角色仍可被吹动，保持冻结姿态。动画在本帧位移后更新，朝向不滞后一帧。

神圣祝福只治疗己方，失能英雄不能复活；成功施放后 150 秒不能抽入手牌，暂停停止冷却，每场重置。过牌保持四张完整且唯一，冷却到期恢复循环资格。九法术接入研究材料、图书馆、战备和休息升级，旧市场商品保持原状，新存档不会直接解锁。

美术沿用暖色绘本风格：五张透明角色图集，每张 16 个姿态，三品质天使共享角色美术；九张法术卡图；六条原创合成施法声音。新增 125 个 UE 资源。黑云复用既有尘雾贴图并在运行时染色，地图、UI 主题、字体和背景音乐沿用已有资源。声音默认注册尊重显式静音和自定义配置；新法术不产生镜头震动。

原生界面新增祝福倒计时、矩形飓风预览、隐藏／受风状态和治疗弹道颜色；长增援名称在手牌中按长度调整字号，720p／1080p 均完整显示。

在独立 D3D12 进程以 1280×720 和 1920×1080 运行，关闭永久档读写及远征自动保存。每种分辨率取得 29 张图，共 **58 张**，存于 `Saved/Screenshots/V083`。目录及 SHA-256 已写入 [验证 JSON](validation/v0.8.3-Release.json)，截图本身属于本地 `Saved` 输出。

- 16 张姿态采样，每张同时展示五种角色，共检查 80 个角色姿态。
- 1 张九法术卡图、阶位与银币费用。
- 8 张真实组件位移驱动的左右步态，2 张停止后待机。
- 1 张黑云、冰冻及飓风，冰冻与黑云放在不同地点便于观察。

## 素材和兼容性

生成 PNG 原始字节、每次实际提示词和返回路径归档在 `ArtSource/StorybookV1/V083/generation.json`。帧工具只读取 alpha 轮廓和元数据，不编辑 PNG；导入资源集中在 `/Game/Art/StorybookV1/V083`。六 WAV 为 48 kHz、16 位、单声道，有首尾淡化，峰值、DC 偏移和格式审计通过；合成参数和种子保留在脚本及声音清单中。

Run Schema 保持 10，Profile Schema 保持 2；效果和种族枚举只追加。内置身份由代码保证，作者数值在私有运行时副本合并。共享地图、蓝图、GameData 和数据表资产没有被本轮写回。真实存档未用来解锁或测试，新法术不会自动进入旧档解锁列表。

当前无需补蓝图、手工下载图片或操作 Music3。可按 [55](55-v0.8.3Guide.md) 打开隔离九法术试玩，直接体验效果与试听。设备上的主观听感、新法术的长期远征平衡仍需试玩反馈；打包与硬件验收继续按此前安排后置。

完整机器记录为 [v0.8.3-Release.json](validation/v0.8.3-Release.json)，包含构建／回归／渲染日志引用、素材导入清单、125 个资源哈希、58 张截图哈希、源码哈希与六个存档前后对照。文本 SHA-256 对应本轮验证的工作区字节，Git 换行转换可能改变文本哈希。
