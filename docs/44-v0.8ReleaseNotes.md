v0.8 integrates the four storybook art/audio batches: 775 Unreal assets, animation for all 28 entities, seven building upgrade illustrations, four locally generated music loops, Chinese fonts, scene transitions, and UI polish. The final gameplay regression passed 83/83 tests on UE 5.8.1. Save schema and combat rules remain unchanged. Packaging, hardware acceptance, and final subjective audio mixing remain deferred. This tag publishes the source project and editor assets.
