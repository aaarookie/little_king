# 小小国王 · 当前游戏设计

更新 2026-09-08 · UE 5.8 · v0.5 基线后的地牢 D3 修订。本文是当前规则依据，取代旧教程中的倒计时、法术门、团队血条、集火优先及英雄永久死亡描述。

## 定位和当前范围

用有限银币和不断轮转的手牌，在自动战斗中保护英雄。营地圈目前仅作显示与未来"营地内 buff"预留，英雄可自由走位；手动移动提供临时撤退和调整站位的机会。国王不出征。

当前实现：一张复用战斗地图、三名玩家英雄、三种玩家佣兵、两法术、两卡牌建筑、五种亡灵敌人，以及按巡逻/精英/首领顺序运行的三房线性远征。D0 数据契约、D1 跨房流程、D2 遭遇配置/英雄永久状态和 D3 奖励构筑已交付；分支路线、存档和家园属于后续范围。全部单位与数值见 [19](19-ContentCatalog.md)。

## 部署与营地

部署阶段没有时间限制。玩家必须放置全部三名英雄（骑士、法师、游侠），每名一次，再主动点击开始；系统不自动补齐玩家英雄。默认镜像敌方自动部署同组三英雄，亡灵遭遇使用独立名单，敌方人数不改变玩家门槛。

点击位置是营地中心。营地有实体圆形占地，默认半径 65；英雄生成在营地边缘外，避免出生重叠。营地属于建筑，但不可攻击、不可摧毁、无血条，不计入单位或建筑卡数量上限；英雄失能后营地保留，不能再下移动指令。

**英雄活动不限距离（2026-09-08 修订）**：英雄不受营地移动半径限制——自动追击、手动移动、单位分离都只在战场矩形内自由进行；普通佣兵同样不受营地限制。营地移动半径（默认 850）保留为**营地范围圈的显示半径**，并为将来的"营地范围内 buff"预留（当前不生效）；范围圈在选中营地时仍会显示。英雄最终站位由指令位置决定。

部署或战斗阶段，点击己方存活英雄的营地，再点击**任意可到达地点**（全图），即可下达移动指令。指令取消当前普攻前摇和正在执行的技能；**移动指令强行打断战斗（2026-09-09 修订）**——下达后英雄立即停止索敌与攻击，即使敌人就贴在攻击距离内也照样走向落点（旧实现会因"敌人已进入攻击距离"当场取消指令，导致战斗中移动点不动）；到达落点后自动恢复索敌与攻击。若落点被单位/建筑占据、或被推挤导致连续 `HeroMoveStuckTimeout`（默认 1.5 秒，`DA_GameData → Camps`）无位移，则结束指令并立即恢复自动战斗，避免卡死。新指令可覆盖旧指令，没有次数和冷却限制。没有目标时英雄返回最近一次指定位置。已经离手的弹道继续飞行。

建筑和营地是硬障碍，移动单位之间使用软分离。目标在障碍内部或没有可用路径时拒绝指令并提示"目标地点不可达"（右键可取消选中）。当前轻量路径算法在很窄的缝隙中可能保守拒绝，不保证任意复杂地形都可导航。

## 战场、经济和出牌

战斗平面为世界 Z=0，玩家半场 Y≤0，敌方半场 Y≥0，中线两侧均可使用。相机采用正俯视，屏幕左右对应世界 Y。Y=0 的黄色分界线由原生 HUD 投影绘制，关闭调试边框或地面覆盖 Z=0 时仍显示。

银币在战斗中持续增长，默认 1/3 每秒，上限 5，开局 0；最终数值以 DA_GameData 为准。本轮没有额外改变经济曲线。

手牌固定 4 槽，合法牌组在初始化完成及每次成功出牌后都保持四槽有牌，同一 CardId 不重复。牌组先移除 None 并按 CardId 去重，只在每场初始化时按种子洗牌一次；前四张入手，其余形成先进先出的待抽队列。成功出牌时，队首立即补入原槽，打出的牌放到队尾；其他三个槽不移动。后续不再洗弃牌堆，也不等待“其他牌解禁”来填空槽。

例如手牌 A/B/C/D，队列 E/F/G：打 A 后手牌 E/B/C/D、队列 F/G/A；继续打 B 后手牌 E/F/C/D、队列 G/A/B；再打 C 后手牌 E/F/G/D、队列 A/B/C；继续打 D 才轮到 A 回手。这样关键牌需要过牌才能再用，且始终没有空槽。这里“有牌”不代表无视银币、单位上限和合法落点。

牌组至少为手牌槽数 + 1 种，即四槽至少五种；当前双方默认七种。重复副本自动归并，去重后数量不足或 CardLibrary 无法解析时不允许开战并提示配置错误。不能通过删牌减到最低数量以下；添加已有 CardId 或转换为另一张已持有 CardId 均拒绝。升级替换原种类，不产生第二张副本；远征中的升级等级和新增卡跨房继承。

前两房胜利后生成 2～3 个确定性奖励候选，并在原生奖励面板中选择一项或跳过。当前候选为升级一张已持有的单位/建筑卡，或获得未持有的骷髅兵/骷髅射手卡。每级升级让该卡出牌生成单位的生命与攻击乘以 1.1，法术、敌方、波次、召唤和兵营产兵不受此升级。奖励批次生成一次后存入 RunState；处理前不能进入下一房，领取、跳过和旧回调均不能重复消费。第三房胜利和任意失败不生成奖励。

单位卡和建筑卡只放在己方半场，必须有足够空间和数量额度。法术为即时圆形效果，按单位中心到落点的二维距离判断命中，与预览半径一致。法术落点合法的空放也消耗费用；无效数据、失败生成、非法落点均不换牌，已预扣银币会退回。零费卡允许使用。

选择箭塔等 Turret 攻击建筑的落点时，显示占地小圈和以落点为中心的基础射程大圈。射程读取建筑单位行 AttackRange；无效落点时圈变红，兵营不画攻击圈。基础预览不包含部署后可能获得的临时战斗属性增益。

同类建筑卡默认上限 2；每队默认 20 个战斗单位（英雄、佣兵、建筑），营地另计。建筑卡配置：-2 继承全局上限，-1 不限，0 及以上为该卡指定上限。

## 英雄特性与目标优先级

技能（既有主动 GA、新增事件被动）与特性（持续规则）分别配置。英雄可以在游戏中增加或删除特性；失能立即停止提供战斗效果。三个亡灵被动不需要 GA；既有法师/游侠 GA 的资产连线问题及修复步骤见 19 / 20。

| 英雄 | 当前特性 | 失去特性或死亡后 |
|---|---|---|
| 法师 | 全场施法：本方所有法术允许在战场任意位置落点 | 法术仍保留在手牌且可选；仅在敌方半场尝试落点时提示“只能放在己方半场” |
| 骑士 | 默认 400 半径内，己方近战佣兵获得嘲讽 | 离圈后刷新移除；死亡/删除特性立即移除；英雄、远程、建筑和营地均不受此光环影响 |
| 游侠 | 本轮不新增特性 | 无变化 |

全场施法是一种可赋予其他英雄的特性效果，逻辑不把“场上有法师”写死为唯一条件。旧 `bIsMage` 只保留身份兼容，不决定法术能否施放。**身份特性（法师全场施法、骑士嘲讽光环、盾卫嘲讽）属于英雄身份**：载入存档时会按当前代码配置补全缺失项（`ULKRunSubsystem::RestoreHeroIdentityTraits`，只加不删），因此老存档不会因为早期版本没把身份特性写进远征快照而丢掉这些能力；房间间用调试命令临时增删的特性仍在本次会话内生效。

目标优先级：有效嘲讽者 > 有效集火目标 > 索敌范围内最近敌人。**索敌范围默认 900 世界单位**（`DA_GameData → Combat → UnitAcquireRadius`；`DT_Units` 行可用 `AcquireRadius` 覆盖，0 = 用默认）：范围内出现敌方单位才会自动锁定并寻路过去战斗；目标死亡或**离开索敌范围（含 15% 滞回）后释放并重新索敌**。无目标的佣兵会向全图最近敌人行军（保证双方仍能接触），英雄保持待命/回到最近指定位置。哨塔只在自身射程内选目标；**集火指令与嘲讽不受索敌范围限制**（嘲讽吸引半径 500 单独配置，嘲讽优先夺取索敌）。多个嘲讽者取最近者。集火不突破队伍/可目标约束，结束时重新评估目标。骑士光环进出范围最多有 0.5 秒刷新延迟。

敌方集火前默认有 2.5 秒头顶感叹号预警。AI 出牌会尝试多个合法候选；反制偏好影响排序，准备爆发时有最多 15 秒的蓄费窗口，不能无限等待。

游侠候选建议（未实现、未定稿）：原地驻守一段时间后扩大附近友方远程的射程，移动后暂时失去加成。它与营地站位形成取舍，须先验证射程叠加是否破坏防线，再决定数值和受益对象。

## 攻击、反馈与结算

AttackInterval 定义为两次普攻起手间隔，前摇包含其中。移动时冷却继续流逝；前摇绑定具体目标，换目标或离开攻击范围时取消。攻击脉冲只缩放精灵，碰撞不变。视觉反馈不暂停战斗计时。

所有可战斗单位（含英雄、佣兵、可攻击建筑）各有头顶简易血条，删除旧团队总血条。营地没有血条。当前仅火球卡和法师火球技能在释放时产生 0.15 秒小震动；英雄死亡、普通单位死亡、治疗及普通攻击均不触发震动。多目标火球一次释放只震动一次。

伤害和治疗记录请求量与实际变化量，飘字显示实际量；满血治疗不飘虚假数字，过量伤害只统计剩余血量。结算记录双方实际伤害、治疗、击杀、成功出牌次数、时间、种子和是否进入虚弱。

一方英雄全灭即失败。默认战斗 480 秒后，双方英雄按同一批次承受递增虚弱伤害，伤害可穿透普通无敌；整个批次结束后才判胜负。若双方同批全灭，比较本局对敌实际伤害（不含虚弱），较高者获胜；相等时用开局已抽定的种子决胜值。这样保留无平局，也避免固定先遍历的一方必败。

结算前先记录最后一击，处理同批死亡/失能被动与骷髅王复活，再判定胜负；王成功复活不算本方全灭。结算后冻结战斗、取消手动移动与技能、回收弹道，并拒绝后续普通伤害和出牌。

## 英雄失能、恢复与亡灵机制

英雄永远不永久死亡。局内生命归 0 为失能，不能攻击、移动、提供特性、成为攻击目标或被普通治疗救起。英雄实例和营地保留到该世界结束，佣兵/普通建筑仍按死亡销毁。普通英雄没有战内复活；骷髅王的朽骨再生是指定例外。

每场战斗结束，**远征房间只对玩家英雄**立即增加 **40% 最大生命**，封顶满血；失能者从 0 恢复到 40%。计算为 `min(MaxHealth, Health + MaxHealth × 0.4)`，例如 20%→60%、90%→100%。恢复不修改已定胜负，不重新开启战斗，不算作战斗治疗。Outcome 同时保留失能标记与恢复前后生命；远征下一房直接继承玩家英雄的恢复后快照，不再额外恢复一次。

**敌方单位状态不跨房继承（BUG-015 规则修订）**：敌方任何单位（英雄/Boss/佣兵/建筑，不限于亡灵）在远征里每房都按遭遇配置满血重建。远征结算不对敌方执行战后恢复（其失能/存活快照只记入 BattleHistory 供展示）；独立单场（无远征）仍保留旧的"双方恢复"调试行为。跨房继承的唯一载体是玩家英雄：`RunState.Heroes` 只允许我方英雄 ID，任何敌方/未知 ID 混入提交都会被拒绝。

远征英雄状态保存当前生命、最终最大生命、永久基础最大生命和永久特性 ID。基础最大生命在新房 Actor 上先恢复，再重新计算永久特性，最后钳制当前生命；因此后续奖励可以安全升级最大生命，删除法师默认特性后也不会在下一房被默认配置重新补回。临时光环来源、强制集火目标、集火预警、攻击冷却、技能冷却和正在移动/施法状态不跨房间。

| 新敌人 | 被动技能 | 英雄特性 |
|---|---|---|
| 骷髅兵 / 骷髅射手 | 无；分别近战/远程佣兵，属于骷髅 | 无 |
| 死灵法师 | 亡灵召唤：敌对佣兵死亡后，按近远程类型原地转换为自己的骷髅兵/射手 | 献祭：每次成功召唤付 8% 最大生命，可因此失能 |
| 骷髅巨人 | 巨骨：己方骷髅兵/射手死亡，自己恢复 3% 最大生命 | 无 |
| 骷髅王 | 朽骨再生：己方其他骷髅佣兵死亡 +1、英雄失能 +5；初始上限 10，倒下时满额则清零、上限 +5、满血复活 | 直面恐惧：受到远程单位、远程建筑、远程技能和法术伤害减少 30% |

一具遗体只由最近的可行动死灵法师转换一次；成功生成才扣献祭代价。死灵法师不是骷髅，不给王加点；王不计自己的失能，同批友军死亡先累加，防止范围伤害遍历顺序改变胜负。虚弱/献祭代价不按远程减免。三个有限波次遭遇由 `DT_Encounters` 配置，奖励档依次为 1/2/3；完整边界和初始数值见 19。美术暂用彩色方框，不增加音效要求。

## 后续路线

Sprint 6 已取消，直接进入阶段 2 地牢。音效与表现素材在后续美术打磨阶段处理，打包和硬件测试在准备发布时安排，不作为开发地牢的前置门槛。用户已反馈数次基础试玩效果不错；这不等同于逐条视觉验收或平衡完成。

详细安排见 [17 地牢开发任务规划](17-DungeonDevelopmentPlan.md)：D0～D3 已完成；D4 分支路线、D5 安全节点存档待完成。当前可走完带两次奖励选择的三房线性远征，尚没有路线选择、休息节点或读档。

跨房间生命规则已按"玩家英雄战后 +40% 恢复并跨房继承、敌方每房满血重建"落地：每次重载战场，用 RunState 的恢复后生命重建三英雄；新远征第一房才满血。战斗银币仍属于单场，首版远征不设独立货币。原“10～15 房间、6 佣兵、3 家园建筑”保留为扩充愿景。
