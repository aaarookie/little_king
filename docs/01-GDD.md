# 小小国王 (Little King) — 游戏设计文档

**版本 v0.2** · 单人开发 · UE5.8 · 2D 自动战斗肉鸽

## 一句话定位

你是小小国王，坐镇家园。派出英雄进入随机地牢，用银币雇佣佣兵、指挥法术与建筑，打一场"保英雄"的自动战斗；凯旋后建设家园、强化英雄，向更深的黑暗前进。

**核心乐趣** = 银币经济的临场决策 × 保护英雄的攻防博弈 × 肉鸽构筑的局局不同

## 核心循环

```
家园(编队·升级·解锁·国王不出征) → 地牢(选路线·进房间·事件获卡) → 战斗(部署英雄·打牌·自动作战) → 奖励(卡牌/银币/材料)
        ↑________________________________________________________________↓
```

## 战斗规则（核心）

1. **部署阶段**：倒计时内于己方半场自由放置 1~5 名英雄（上限随进度解锁；**国王本人不出征**，坐镇家园）。双方就绪或倒计时结束即开战。
2. **战场**：矩形平地，玩家在左半侧，敌方在右半侧；单次战斗在此场地内完成。（后期可引入自带建筑/地形特性的战斗场地。）
3. **经济**：每秒 +1~2 银币（上限 10~20），数值随进度/局内强化成长。
4. **卡牌**：手牌上限 4，打出自动补一张；牌库耗尽洗回弃牌堆（杀戮尖塔式循环）。牌库 = 战前构筑 + **地牢事件获得的新卡**。
5. **卡牌类型**：角色（佣兵·限己方半场）/ 法术（即时·可全场）/ 建筑（防守·限己方半场）。
   - **法术门**：场上存在法师英雄时，法术卡才可加入战斗手牌并在战斗中释放；法师阵亡后法术锁定。
6. **自动战斗**：单位自动索敌（最近优先，可被"嘲讽"等特性改写）→ 移动 → 攻击 → 放技能。
7. **胜负**：一方英雄全部阵亡即败；**无平局**——超时（8 分钟）后英雄陷入虚弱状态，虚弱 debuff 强度随时间上升，最终自然分出胜负。

## 英雄

高属性 · 多技能 · 带特性（光环/羁绊）· 不耗银币但数量有限 · **阵亡不复活**（后期可能推出自带复活特性的英雄或复活法术，作为机制例外）。
**保英雄 = 核心策略**：敌方会集火英雄，你必须用佣兵、建筑、法术构筑防线。

## 建筑规则

- 建筑**种类无上限**（实际受战场大小与手牌上限约束）。
- 同类建筑通常 ≤2（可配置）；后期可加入不受同类上限限制的建筑。

## 三大支柱（开发优先级）

| 支柱 | 内容 | 优先级 |
|---|---|---|
| 战斗 | 银币 · 卡牌 · 放置 · 英雄保护 · 法术门 | ★★★ 先做 |
| 地牢 | 路线节点 · 随机事件（获卡来源）/商店/Boss · 局内构筑 | ★★ |
| 家园 | 建筑升级 · 英雄养成 · 内容解锁（国王视角） | ★★ |

## 美术 & 音乐

- 2D 卡通风格，AI 生成（ChatGPT image）；**程序动画为主**（待机浮动/受击闪白/技能粒子），后期按需 Spine。
- BGM：MiniMax Music 3（主菜单/战斗/地牢/胜利/失败/家园 6~8 首）；音效：免费素材库 + AI 补充。

## MVP 范围（垂直切片）

1 张战斗图 · 3 英雄（含法师） · 6 佣兵 · 2 法术 · 2 建筑 · 1 层地牢（10~15 房间：战斗/奖励/事件/商店/Boss） · 3 家园建筑 · 单机 PvE。

## 已定设计决策（v0.1 → v0.2）

| 议题 | 决策 |
|---|---|
| 国王是否出征 | 不出征，坐镇家园；战场部署的是英雄 |
| 英雄复活 | 通常不复活；后期机制例外（复活特性/法术） |
| 战场形态 | 矩形平地，玩家左半侧；后期场地可自带建筑/地形 |
| 新卡来源 | 地牢事件 |
| 平局 | 无。超时 8 分钟 → 英雄虚弱 debuff 随时间增强 |
| 建筑上限 | 种类无上限；同类通常 ≤2，可配置，后期有例外 |
| 法术限制 | 需法师英雄在场（加入手牌与释放均受此约束） |

## 开放问题（地牢/家园阶段再定）

1. 地牢事件的具体形式与卡牌稀有度分布
2. 虚弱 debuff 是"双方英雄"还是"劣势方英雄"（原型按双方实现，可配置）
3. 分路战场（原型单路，尺寸参数化预留）
