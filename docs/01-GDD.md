# 小小国王 · 当前游戏设计

基线：v0.8.6。本文只记录现行玩法；默认数值与技能边界见 [内容图鉴](19-ContentCatalog.md)，实现契约见 [技术设计](02-BattlePrototypeDesign.md) 和 [卡牌接口](34-CardDevelopmentInterfaces.md)，阶段交付见 [开发历史](DevelopmentHistory.md)。接手约定见 [项目交接](64-ProjectHandoff.md)。

## 定位与范围

UE 5.8 单机 PvE 自动战斗：在家园配置三名英雄和牌组，从大门出征，以银币出牌并指挥英雄走位，沿随机路线带回金币及研究材料。国王不出征。

当前有七座家园建筑、五个固定地理区域、46 个单位、48 张注册卡。卡牌包括初始七张、敌方专属三张、临时佣兵十四张、研究法术十六张和研究建筑八张；十一种天使只有召唤单位定义。地牢 D0–D5、家园 H0–H5、美术及声音已接入。

战场工坊可编辑四地形、敌人、建筑、条件／定时增援与敌方经济，设计 JSON 能启动独立 UE 战场。它尚未自动分配到远征节点，也不生成 `.umap`；完整边界与 v0.8.5 验证见 [地形与遭遇](62-TerrainAndEncounterDesigner.md)。打包、硬件和长期平衡验收仍后置，下一阶段功能由用户确定。

## 远征路线与结算

路线为西境原野 → 霜落高地或暮色湿地 → 断壁关隘 → 白骨王庭，通常经过四区。区域边界、入口和出口固定；内部节点及有向连接按本轮种子生成并保存，只展示当前区域。新地图每区十五层、约 29–43 个总节点；实际路径约十五站，包括九至十场战斗、两市场、三休息。首区起点已解决，因此少一场战斗；所有边向前，不可回头或重复消费，旧地图保留原布局。

普通战一名敌方英雄，精英战多名，首领战包含 Boss 与英雄。非终点胜利生成至多三个冻结奖励候选：新增临时佣兵或升级已有佣兵，可选一项或跳过。新市场至多五件：三件临时手牌（优先佣兵、法术、建筑各一），一件饰品／装备道具，一件可研究法术书或建筑图纸。商品按地区、品质和本轮银币上限过滤；研究排除永久已解锁和已有材料，优先当前最高合格地区档。无合格候选时允许空类别。临时手牌不永久解锁，道具不占手牌容量。市场内容、售出状态和奖励读取存档后不重抽。

休息节点在全体玩家英雄恢复 30% 最大生命与升级一张法术／建筑之间二选一。升级只对本轮有效，按 `1.1^Lv` 放大对应数值；费用、范围、品质、人数和技能机制不随升级变化，特殊效果的升级字段见图鉴。

出发本金由家园转入远征钱包，金库仅限制携带本金，途中收入不受该限额约束。普通／精英／首领奖励档金币为 10/20/40，完整通关额外 +20。成功或主动放弃带回剩余金币 100%，失败带回 80% 并向下取整；市场消费不返还，已购材料和道具在所有结局都全数带回。结算使用稳定 ID 幂等入账，保存失败回滚。

远征中不允许暂回家园。非战斗节点可确认放弃后回家；战斗／部署期间只能暂停后退出至开始界面。读档恢复已选战斗的战前英雄、牌组、生命、敌阵和种子，不能改选分支或刷新商品。暂停停止游戏时间、技能、银币、增援、法阵和抽牌冷却。

## 编队、容量与过牌

三位英雄独立编队，正式出征至少七种唯一且已解锁的卡。部队默认容量八格：巨魔两格、巨像三格、其他卡一格；这与四槽手牌、战场人数分别计算。远征内至少保留五种卡。

固定容量超额获取时，必须释放最少必要格数，同释放量优先弃更少张；动态合法区间（如 8–10）允许所有最终占格落入区间且满足最低卡种数的方案，包括未超上限时主动弃牌。确认前保留旧卡；替换、钱包、材料和节点消费一次保存，失败全部回滚。新卡从 Lv0 开始，旧卡强化不转移。临时佣兵跨房和本轮读档有效，远征结束后不进入永久收藏。

玩家牌组初始化过滤空 ID 并去重，按种子只洗牌一次：前四张入手，其余形成先进先出队列。成功出牌后，首个可抽队列项补入原槽，打出的牌进入队尾，其他槽不移动；四槽始终补满且 CardId 不重复。无效牌库、重复添加或转换为已持有卡均拒绝。敌方使用独立规则：启用卡牌时至少一张，单卡可循环；两张以上手牌槽数为 `min(4, 卡种数-1)`。

神圣祝福成功施放后 150 秒不能再抽取，冷却卡保留在队列中；到期恢复过牌资格，每房重置，暂停停止。施放任何冷却卡前都要保证还能维持四种可用手牌。

## 部署、营地与移动

部署不限时，玩家必须放齐骑士、法师、游侠，再主动开战。敌方人数由遭遇配置决定，不改变玩家三英雄门槛。

营地中心固定，默认实体半径 65，英雄出生在边缘外。营地不可攻击、不可摧毁、无血条，不计战斗单位或建筑卡上限。英雄失能后营地保留但不能下移动指令。默认 850 的营地范围圈只用于显示和未来效果预留，英雄活动不受其限制。

玩家可以通过营地指挥存活英雄前往全图任意可达地点。新指令打断普攻前摇和技能，移动期间停止索敌与攻击；到达或连续 1.5 秒无位移后恢复自动战斗。新指令可覆盖旧指令，已发射弹丸继续飞行。没有目标时英雄回到最近指定位置；驻守／就诊期间服务关系优先于营地指令。

建筑、营地与阻挡地形是硬障碍，普通移动单位使用软分离。目标在障碍内或无可用路径时拒绝指令。墙体封闭战斗目标时允许先破墙；大量障碍下的窄通道可能被寻路保守拒绝。

## 战场经济与出牌

战斗平面为 Z=0，玩家半场 Y≤0、敌方半场 Y≥0，中线两侧均可使用；相机画面左右对应世界 Y。黄色中线常显。单位／建筑卡只能放在己方半场的合法空位；法术通常为圆形范围，按单位中心的二维距离判断命中。

基础银币产速每秒 1/3、上限 5、开局 0；家园金库改变玩家出征快照，敌方按遭遇配置。每队默认最多 20 个战斗单位（英雄、佣兵、建筑），营地另计。同类建筑默认上限 2；卡牌可继承、取消或指定上限，墙卡默认取消同类限制，仍受全局人数限制。

出牌须同时满足银币、单位上限、权限及落点。合法空放仍扣费并过牌；非法请求、无效数据或生成失败保留手牌并退款。零费卡可正常使用。攻击建筑预览基础射程和占地，墙体预览完整轮廓及朝向。

法师的全场施法特性允许本方法术全图落点，失能后普通法术限己方半场，卡牌仍可选择。四档圣玛丽亚增援自身允许全场合法落点，神圣祝福作用于全场己方，二者不依赖法师。黑云隐藏双方单位但不免疫地面法术；雷电只选敌方非英雄；飓风推动双方可移动角色，营地与固定建筑不动。

## 战斗、英雄与目标

技能和持续特性分开。骑士默认半径 400 内的己方近战佣兵获得嘲讽，最多 0.5 秒刷新；不影响英雄、远程、建筑和营地。法师提供全场施法；游侠暂无额外特性。英雄失能或删除特性即停止提供效果。身份特性在载入时按代码补齐缺失项，房间间临时增删在当前会话内生效。

通常目标优先级为有效嘲讽者 > 有效集火目标 > 索敌范围内最近敌人；哥布林大盗的嘲讽免疫和背刺锁定是特例。默认索敌半径 900，表行可覆盖，目标离开含 15% 滞回的范围后释放。无目标佣兵向全图最近敌人行军，英雄待命或归位；哨塔只在射程内选目标。集火和半径默认 500 的嘲讽吸引不受普通索敌半径限制。

敌方集火前默认预警 2.5 秒，出牌尝试多个合法位置；准备爆发最多蓄费 15 秒。普攻间隔包含前摇，移动期间冷却继续，目标变化或离开射程取消前摇。只有实际火球卡／火球技能释放产生 0.15 秒小震动。

所有可战斗实体有头顶血条；伤害、治疗和飘字记录实际生命变化，满血治疗和过量伤害不虚增统计。牧师普攻只治疗受伤友军，失能英雄不能被普通治疗救起。

普通战斗一方英雄全部失能即败。默认 300 秒后双方英雄按同一批次承受递增虚弱伤害，穿透普通无敌；同批全灭按对敌实际伤害（不含虚弱）比较，相等则用开局种子决胜。批次先记录最后一击、死亡被动和骷髅王复活，再判胜负。自定义布局战场的胜利还等待清敌与未来定时／已触发条件波次，详见地形与遭遇文档。

英雄生命归零为失能，保留实例与营地，停止战斗和特性；骷髅王满额复活是战内例外。远征战后仅玩家英雄恢复神像快照对应的最大生命比例，封顶满血，失能者从零恢复；该恢复不改变胜负也不计战斗治疗。下一房继承恢复后生命、永久基础最大生命及特性。敌方每房满血重建，光环、冷却、控制、临时单位及指令不跨房。

## 家园与存档

永久进度、当前远征和当前战斗分开保存。家园升级与战备在创建 RunId 时冻结为出征快照，整轮不追套后续变化；战斗银币、手牌与场上实体每房重建。

| 圣玛丽亚神像 | Lv1–4，战后玩家英雄恢复最大生命 40/60/80/100%；升级金币 60/120/200。不影响战内治疗或休息的 30% |
| 金库 | Lv1–5，银币上限 5/7/9/11/13，每级产速增加基础值 10%；升级金币 50/100/160/240；出征本金上限 100/150/200/250/300 |

默认入口 `L_StartMenu`，支持继续、新建、读取／确认删除，最多八档，设置仍为占位接口。每档拥有独立永久档 A/B 双副本与远征文件；01 档兼容 `LittleKing_Profile_A/B`、`LittleKing_Run`，02–08 使用编号前缀。永久档候选写入并读回校验后才发布，不可读档保留且占位，不自动覆盖。

当前 Run Schema 11、Profile Schema 3。迁移保留旧地图、种子、冻结商品及已结算回执，不自动解锁新内容；旧五／六卡战备仍可读取，下一次出征需补至七种。超额旧牌组保留并要求显式裁减，不静默删卡。最近有效档按保存／使用时间确定。
