# v0.8.2 远征规则、研究与暂停：协作记录

日期：2026-09-30。本轮包含上一轮尚未发布的 Balance V1；最终发布版本为 0.8.2。本文件随实现更新，验收完成前不把规划写成已验证结果。

## 已确认规则与实现安排

1. 治疗波采用固定治疗量与英雄最大生命比例组合，保留范围治疗、失能者不能被战内救起的规则。升级只提高数值。
2. 出征至少携带 7 种卡；战内四槽唯一循环仍要求至少 5 种。容量为本轮冻结的动态规则，默认上限 8。固定上限：在合法候选中最小化弃牌释放的格数，同释放量再最小化弃牌张数；合法区间（如 8～10）允许任意弃牌组合，只要最终格数落入区间且卡种足够。新卡与弃牌同一事务保存。
3. 战斗奖励只新增远征临时佣兵、或强化佣兵；建筑和法术只能在休息节点强化。本版只调整生命/攻击、法术效果数值。
4. 市场商品按远征种子和节点生成并冻结。只出售临时佣兵及极低概率、昂贵的法术书/建筑图纸；新法术、建筑在家园图书馆消耗研究材料永久解锁。高阶书籍按区域进度门槛出现。已购买书籍/图纸在成功、失败和放弃后均带回，用户已明确确认。
5. 失败带回钱包剩余金币的 80%（向下取整）；放弃带回 100%。战斗或部署中不得放弃。
6. 战斗暂停提供继续和退出至开始界面；退出保留已选择的当前战斗、敌阵/种子和战前英雄/牌组快照。读档重打同一房，不退回岔路口。暂停期间游戏时间、经济、技能、增援和法阵均停止。
7. 远征期间的奖励、选路和服务节点均提供退出至开始界面及明确放弃回家。活动远征不允许直接暂回家园；继续游戏直接恢复远征。
8. 用户确认“15 个节点”指每个区域局部地图：一条路径约 15 个节点、约 10 个战斗节点。节点总数含分支会更多。远征视图只显示当前区域，进入后继区域才展示新区域；已创建的旧图保留，不能重抽。
9. 完成构建、自动化、实际 UI 检查、真实存档校验后更新中英文 README、版本号、发布记录，提交并通过 HTTP 18081 代理推送主线和 v0.8.2 标签。

## 工作分块

容量/数值与卡牌身份 → Run/Profile 新字段及迁移 → 市场与研究事务 → 休息升级 → 暂停/恢复/导航 → 局部地图生成与显示 → 数据资产及文档 → 验证与发布。

生产逻辑使用稳定 ID，金币、物品授予和研究均在保存成功后发布。旧的结算回执保持冻结金额，禁止重复入账。真实玩家档只核对哈希，不用于迁移测试。暂不增加打包或硬件测试。

## 实现清单与验证

### 实际交付

九项需求均已实现；上一轮 Balance V1 的代码、实际数据表和验证也合并进本版。版本号为 `0.8.2`，中英文 README 已同步。无须用户补建界面或下载资源。

治疗波采用 `(120 + 英雄最大生命 × 0.06) × 1.1^本轮等级`；非英雄没有比例项，实际治疗按缺失生命封顶。Lv0 骑士／法师／游侠分别恢复 480／372／408，失能者仍不能战内救起。费用二、半径三百未改。实际 `C_HealWave` 与代码回退同步；学徒模仿也使用被模仿法术的本轮等级、固定量和英雄比例。

默认容量 8/8 表示固定上限：算法先在满足五种循环卡底线的方案中最小化释放格数，同释放格数再最小化弃牌张数。例如 7+2 时只弃一格；如果没有一格卡，则允许最少可行的两格。8+2 时若一张两格与两张一格都可行，则选择一张两格。合法区间 8/10 不进行此最小化，9+1 不弃、弃一格或弃两个一格都合法。容量支持最多 64 格，运行中的安全节点可调用 `SetDeckCapacityRule` 调整；市场、奖励、保存和 UI 都读取本轮规则。

市场默认冻结三种临时佣兵，商品单次出售；价为 `20 + 银币费用×15 + 品质索引×10`。每市场 1% 概率抽取一本法术书，深度达标后才参加阶位加权；图纸从区域深度 1 起有 0.5% 概率。初版七个研究法术及攻城投石炮图纸的价格、深度、数值见 [51](51-v0.8.2Guide.md) / [19](19-ContentCatalog.md)。材质／图标复用既有绘本资源，来源补记于 [36](36-ArtAudioSources.md)。

休息节点在全体恢复 30% 最大生命与一张法术／建筑升级之间选择一次。升级只增加效果、生命／攻击，费用／范围／射程／间隔不改，不让兵营生成单位继承建筑等级。战斗奖励保留佣兵新增／升级，不再新增或升级建筑与法术。攻城投石炮作为建筑改为图纸研究永久解锁，旧轮已有炮保留。

### 保存、迁移和失败处理

Run Schema 从此前 8／9 升至 10，Profile 升至 2。活动旧档继承原地图与英雄／卡牌；市场若从未生成，按稳定种子生成一次后保存。已有已冻结结算回执的金额保持不变，活动旧轮的新失败规则为 80%。旧奖励中的非法新增法术／建筑候选在迁移时过滤，已有卡不删除；更早 Balance 迁移沿用独立兼容步骤。

旧五／六张战备可以加载，不让整个永久档变成坏档；下一轮出征必须补至七张。运行中至少五种牌，超额旧牌组不静默裁减。所有候选先校验并保存／读回，再发布；保存失败时购买、弃牌、材料、研究解锁、升级及节点消费一并回滚。不可读／未知版本文件保留并提示。

退出战斗只把 Run 从 `InBattle` 改为 `EnteringBattle`，保留同一个 PendingBattle：已选 NodeId、AttemptId、Encounter、敌阵、Seed 及战前英雄／牌组不变。继续游戏直接恢复这一场，不能回岔路口。商品 OfferId、价格、售出标记与钱包交易回执随地图冻结，读档不刷新市场。

成功／失败／放弃结算均通过结算 ID 防重入；金币和材料一起进入永久档，研究通过同一候选消耗材料与解锁卡。失败为 `floor(剩余金币×0.8)`；101 金币带回 80。部署／战斗及暂停界面均没有放弃入口，底层也拒绝放弃。
