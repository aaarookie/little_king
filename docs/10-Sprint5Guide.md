## 二、我（C++）实现内容

### 1. 攻击节奏改造

```
FLKUnitRow 新增字段 AttackWindup（前摇，0~0.25s，默认 0.15）
状态机：进入攻击 → 前摇计时（站定，可被打断重选目标）→ 前摇结束才：
  近战：结算伤害；远程：发射弹道
攻击时程序动画：缩放脉冲（攻击瞬间 1.15 → 1.0，约 0.15s 回弹，Tick 内插值）
```

### 2. 打击反馈

- **受击闪白**：受伤瞬间 `SpriteComponent->SetSpriteColor(白)` 0.08s 后恢复（纯 C++，无需资产）
- **死亡表现**：死亡后 0.35s 内缩放缩小 + 淡出再销毁（替换现在的 0.5s 直接消失）
- **屏幕震动**：候选方案（实现时选能跑且稳定的）：
  - 方案 A：PC 相机震动（`ClientStartCameraShake`，可能需要你建 1 个相机震动蓝图资产）
  - 方案 B（保底）：编辑器场景相机位置做 2~3 帧小幅抖动（无资产依赖）
  - 触发点：英雄死亡（大震）、普通单位死亡（小震）、法术命中（中震）
- 命中停顿（Hit Stop）：在"受击闪白"同一时刻让攻击者停顿 ~0.06s（移动暂停计时），增强打击感

### 3. 伤害飘字数据链（C++ 部分）

```
所有伤害/治疗出口（LKGameplay::ApplyDamage/ApplyHeal）→ 转发到
GameMode 事件：OnDamageEvent(FVector 世界位置, float 数值, bool 是否治疗)
HUD 基类（我加）：把该事件透传为蓝图事件 OnDamageEventBP(...)，
并给两个工具函数：WorldToScreen(世界位置)（投影到屏幕坐标）
飘字控件与动画由你按教程 A 做
```

### 4. 音效触发点（C++ 部分）

```
ULKGameData 新增：TMap<FName, TSoftObjectPtr<USoundBase>> SoundMap
+ 播放器函数 PlayLKOneShot(声音ID, 位置, 音量倍数)
触发点（内置调用）：近战挥击 / 远程发射 / 受击 / 单位死亡 / 出牌 / 开战 / 胜利 / 失败
```
> 你只需要导入音频资产并在 DA_GameData 填表；没填的触发点静默跳过，不会报错。

### 5. 弹道对象池 + 性能粗查

```
ALKProjectile 改对象池：GameMode 持有池（预生成 32 个）
命中/超时 → 回收（隐藏+停用）而非 Destroy；发射 → 激活复用
性能粗查：100 单位同场 PIE 帧率观察 + ListUnits 自查
```

## 三、你要做的（教程）

### 教程 A：伤害飘字 WBP_DamageText

**A1. 建控件**
```
内容浏览器 → 添加/导入 → 用户界面 → Widget 蓝图（父类默认 UserWidget 即可）→ 命名 WBP_DamageText
层级：根画布 → 一个文本（Text）
文本设置：字号 18~22、白色、描边黑（外观→阴影）
```

**A2. 做上浮动画（UMG 动画）**
```
WBP_DamageText 底部有"动画"（Animations）面板 → 点 + 新建动画，命名 FloatUp
选中文本 → 点"轨道 +"添加关键帧：
  0.0s：位置 Y=0，不透明度 1
  0.8s：位置 Y=-80（往上飘），不透明度 0
保存动画后，删除时间轴面板里自动加的默认帧以外内容（保持只有这两段）
```

**A3. 接到事件（WBP_BattleHUD 蓝图）**
```
覆写下拉 → OnDamageEventBP（Sprint 5 C++ 提供）
→ 执行线：创建控件（Create Widget）→ 类 = WBP_DamageText
→ 世界位置 → WorldToScreen → 结果接"设置位置"（Set Position）? 
  简化：新建控件后 AddToViewport → 用"把世界坐标转到视口"类节点定位
  （确切节点名实现时在教程里补图）
→ 文本内容：伤害显示"-120"（红），治疗显示"+150"（绿）
   —— 在 WBP_DamageText 里加两个公开变量（数值文本/颜色），创建后设置再播放
→ 播放动画 FloatUp → 动画完成回调 → 从父级移除（Remove From Parent）
```
> 飘字会很多：先在"普通单位"伤害上试通，再开放所有伤害源。性能不佳时改"伤害数字池"（复用控件实例，Sprint 6 处理）。

### 教程 B：音效素材与填表

1. 素材来源：MiniMax Music 3 出音乐；**音效**（挥击/命中/死亡/UI 点击）用免费素材库（freesound.org 等）或 AI 生成，导出 **WAV**（短促、48kHz 单声道即可）
2. 导入：全部拖入 `Content/Audio/`（会自动转 UE 格式）
3. 打开 `DA_GameData` → 搜 **Sound Map**（Sprint 5 C++ 新增）→ 添加键值对：
   | 键（触发点） | 建议 |
   |---|---|
   | MeleeHit / RangedShoot / UnitDied / CardPlay / BattleStart / Victory / Defeat | 对应音效资产 |
4. 没配的键静默跳过，可以先只配 3 个感受流程

### 教程 C：HUD 美化

按你的 [07-ArtStyleGuide.md](07-ArtStyleGuide.md) 统一视觉：
- 卡槽：圆角边框、选中态（放置模式时描边高亮——可用已有的 OnPlacementStateChanged 事件）
- 按钮：统一样式（Normal/Hovered/Pressed 三态已在部署面板用过，推广到手牌）
- 字体/字号层级：标题 > 卡名 > 数值；禁用默认字体锯齿问题用"轮廓"或阴影
- 底部手牌区加个半透明底板（Image 拉伸），提高可读性

### 教程 D：验收清单

- [ ] 攻击有前摇感、命中瞬间有闪白/停顿反馈，不迟滞
- [ ] 单位死亡是"缩小消失"而非瞬消
- [ ] 伤害飘字正确跟随战斗位置、治疗与伤害颜色区分
- [ ] 英雄阵亡/法术命中有屏幕震动（任选方案）
- [ ] 6~8 个音效触发点至少配 3 个且不刺耳
- [ ] HUD 视觉统一（对照风格指南）
- [ ] 弹道池生效：一场 3 分钟对局无弹道泄漏（日志无 Destroy 报错）
- [ ] BugLog + Git tag v0.5

## 四、风险与坑

| 坑 | 说明 |
|---|---|
| 前摇加完手感变"肉" | AttackWindup 从 0.1 起步微调，超过 0.25 会明显迟滞 |
| 飘字刷屏 | 先把飘字限制在"击杀/暴击/治疗波"，再决定要不要全量 |
| 音效音量 | 播放器带音量倍数参数，素材响度不一时在填表处统一调 |
| 对象池泄漏 | 池回收要覆盖"超时/命中/对局结束"三条路径，结束对局时统一清池 |
| 相机震动过度 | 震屏幅度做成 GameData 可配（我加字段），晕 3D 的同事/自己可关 |

## 五、执行说明

打击感是"体感迭代"：每轮改 1~2 个反馈 → 你 PIE 打一局 → 反馈手感 → 再调。建议一次会话内完成 2~3 轮小迭代再进下一项。
