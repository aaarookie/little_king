## 核心参数

| DA_GameData 字段 | 默认 | 意义 |
|---|---:|---|
| HeroCampMoveRadius / HeroCampBodyRadius | 850 / 65 | 移动圈外缘 / 固定营地体积 |
| UnitBodyRadius | 50 | 普通单位逻辑体积，与精灵大小分离 |
| KnightTauntAuraRadius / TauntAcquireRadius | 400 / 500 | 获得嘲讽的光环范围 / 敌人受吸引范围 |
| FireballShakeIntensity / CameraShakeScale | 10 / 1 | 火球释放时的世界单位小震，倍率 0 可关闭 |
| AIFocusWarningSeconds | 2.5 | 集火前预警 |
| AIPushReserveMaxSeconds | 15 | 最长蓄费窗口 |
| BattleSeed | 12345 | 对局随机种子，牌库分别用其 +1 / +2 |
| bNativeDamageText | true | 原生实际量飘字；关闭后才转给旧 OnDamageEventBP |

法师死亡不导致灰卡；敌方半场落点才报错。营地不受任何伤害、不显示血条、不计建筑卡上限。英雄死亡不震动。AttackInterval 包含前摇，移动不暂停冷却。

## 完成标准

- [ ] 本机读取 15 中最新构建与自动化结果，并可重跑。
- [ ] 所有旧团队血条和旧锁法术蓝图分支已删除，全部相关蓝图编译通过。
- [ ] 未部署完三英雄无法开战，等待任意时间都不自动开始。
- [ ] 三营地可独立指挥；英雄绕实体走，到达恢复攻击；战斗结算后冻结。
- [ ] 手牌连续出牌四槽有牌且不重复，队列按序回手，法师死后己方半场可施法，敌方落点拒绝且不扣费。
- [ ] 骑士近战佣兵嘲讽覆盖集火，离圈/删特性/死亡能撤销。
- [ ] 头顶条不挡角色，只有两类火球释放震动；营地、预览、弹道、预警可辨识。
- [ ] 选择箭塔落点时看到基础射程圈；取消后消失；兵营不显示攻击圈。
- [ ] 关闭 Draw Field Bounds / Draw Debug Shapes 后，中间黄线仍显示；普通对局与重开可用。

上述未勾项是可复用的短功能检查清单，不代表用户此前没有做过试玩，也不自动要求重做每项。最新自动化与蓝图结果按 15 记录；音效、素材、打包、硬件专项不在本阶段完成标准中。地牢以 17 的任务批次推进。
