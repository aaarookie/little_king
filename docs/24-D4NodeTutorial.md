# D4 · 分支路线与节点选择 UE 5.8 教程（验证为主）

适用版本：UE 5.8.1，D4。**C++ 逻辑与原生界面已完成并通过 29/29 自动化**；本批次没有必须由你在编辑器里制作的资产/蓝图——原生节点选择面板由 C++ 直接构建。你只需按本文做一次 PIE 手工验收。

## 1. 本次规则（按你的要求实现）

- **图结构（每局相同形状，内容随机）**：
  ```
  第 1 战：普通房（敌方英雄 = 从敌方英雄池随机 1 名）
       ↓
  下一排：普通房（随机 1 名） + 休息营地 → 二选一
       ↓
  下一排：精英房（随机 2 名不同英雄） + 休息营地 → 二选一
       ↓
  首领房：1 名首领（骷髅王） + 随机 2 名英雄
  ```
- 每打完一房并领取/跳过奖励后，进入**节点选择界面**——只显示**下一排**可选节点，看不到更后面
- 休息营地：目前唯一选项"恢复 30% 最大生命"（全体英雄，封顶），选择后立即生效并继续显示再下一排
- 敌方阵容从遭遇表推导：**Boss 行（Rank=Boss）的英雄里首领进首领池、其余进英雄池**——以后往 `DT_Encounters` 加新行/新英雄会自动进入随机池（数据驱动，不写死骷髅）
- 同一种子 → 同一张图、同一批敌方阵容（确定性）；奖励种子独立

## 2. 界面长什么样（原生，无需你做）

| 时机 | 界面 |
|---|---|
| 打完一房胜利 | 奖励面板（D3）→ 领取/跳过 |
| 奖励处理完 | **节点选择面板**：两个大按钮（普通战·敌人：xxx / 休息营地·恢复 30%） |
| 选择休息 | 面板刷新显示再下一排，提示"已恢复 30% 生命" |
| 选择战斗 | 自动重载战场进入该房 |
| 失败 / 首领通关 | 结算按钮"从头开始"（可点击） |

自定义外观：`ULKBattleHUDWidget` 类默认值可指定 `NodeSelectWidgetClass` 为 `ULKRunNodeSelectWidget` 的蓝图子类（换肤），与 D3 奖励面板同一模式。

## 3. PIE 手工验收脚本

1. 打开 `L_BattleTest` → Play（自动开局）
2. 部署三英雄 → 开战 → 胜利（可 `~` + `WinMatch 0`，战斗开始后）
3. 奖励面板领取/跳过任意一项 → 应弹出**节点选择面板**，且只有 2 个选项
4. 日志检查（`~` 已开时输出）：
   - 开局 `[Run] 生成路线失败` 不应出现；`新远征 … 节点 7`
   - 每房进入日志 `加载第 N/4 战 Enc_Dyn_Rx`
   - 选休息 → `[Run] 休息：全员恢复 30% 最大生命（封顶）`；再看下一排
   - 选战斗 → `选择 Node_R… 进入战斗`
5. 验证随机敌人：同一局不同房敌人不同组合；开两局（不同 BattleSeed）第一房敌人可能不同
6. 全战斗路线通关一次；选一次休息路线通关一次；故意失败一次 → 按钮"从头开始"
7. 首领房胜利 → 无奖励、无节点选择，按钮"从头开始" → 点击后新远征（房一满血、图重抽）

## 4. 常见问题

| 现象 | 处理 |
|---|---|
| 胜利后没有节点面板 | 检查奖励是否已领/跳过；面板在奖励消费后出现（顺序敏感） |
| 休息选项点了没反应 | 面板按钮仅在选择后短暂锁定；若日志出现 `拒绝选择` 说明状态已变化，重开面板 |
| 想看后面路线 | 设计如此：只显示下一排，看不到后续 |
| 想验证随机性 | 对比两局第一房敌人；或控制台 `ListRunState` 看当前节点与遭遇 |
| 想改敌方阵容池 | 编辑 `DT_Encounters` 加行/加英雄（新增普通/精英行 → 自动进英雄池；新 Boss 行首位=首领） |
