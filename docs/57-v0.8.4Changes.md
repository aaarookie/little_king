# v0.8.4 · 城防、攻城与驻守建筑

开发验收与发布：2026-10-08，`main` / 注释标签 `v0.8.4`。本页合并本版变更与发布记录，数字为**v0.8.4 历史结果**。当前玩法与数值见 [01 GDD](01-GDD.md)、[19 图鉴](19-ContentCatalog.md)，扩展契约见 [34 开发接口](34-CardDevelopmentInterfaces.md)，素材来源与生成记录见 [36 来源台账](36-ArtAudioSources.md)。

## 阶段结果

新增普通/稀有/史诗/禁军四种防御墙、移动攻城车、法师塔和牧师治疗站，共七单位/七卡。通过市场图纸和家园研究解锁，旧档不自动授予，已生成市场保持冻结。本版图纸目录扩至八种，并按区域与权重抽取。

墙体完成有向放置、Q/E 旋转、部分重叠、施工、修补与替换。修补/替换按品质判断，匹配旧墙时保留原位置和正反朝向；失败生成保留费用、手牌和旧墙。施工结束后才阻挡、反弹及提供光环。普通单位绕行，完全封闭时破墙；精确墙段轮廓贯穿预览、边界、出生、寻路、近战与投射物。

攻城车寻找最近可攻击敌方建筑并走到攻击距离，百分比伤害对墙翻倍。驻守建筑预约符合职业且可达的友军，英雄优先；走入后隐藏驻守者并提供保护。法师塔加快技能冷却，治疗站由牧师一次接诊一名低血比患者、治满归队；预约、入口拥堵、死亡与建筑损毁都清理双向状态。患者仍在建筑外可受攻击。所有牧师普通攻击统一为治疗友军，精灵牧师原被动保留。

原生界面加入墙体方向、前后光环、修补/替换说明、施工进度、驻守身份和患者反馈。七卡图、攻城车动作与七条合成音效完成导入，共新增 78 个 UE 资源；音效限流保留自定义覆盖和显式静音。

内置身份与行为来自代码，合法数值/几何/作者素材在私有副本合并；CardId 与 UnitId 不互换，不推断未知扩展卡。新增建筑枚举仅追加，Run Schema 10 / Profile Schema 2 不变。新内容无需补数据表或蓝图，不重建旧市场，也不回写共享资产。

障碍不超过十二个时使用精细可见图，超过时切为网格 A*，最多 8,192 节点；采样点、边和收直仍检查精确几何。大量障碍中的极窄通道可能保守判为不可达。缓存只保存几何值，不持有 Actor/World/存档；几何改变后失效。相关接口与当前契约归 34。
