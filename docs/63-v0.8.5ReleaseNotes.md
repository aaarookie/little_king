# v0.8.5 战场编辑器发布记录

发布日期：2026-10-09。工程版本 `0.8.5`，分支 `main`，标签 `v0.8.5`。本版主要交付战场工坊：可以搭建地形、敌人和建筑，配置增援及敌方经济，再用导出的 JSON 启动真实 UE 战斗。详细操作见 [61](61-BattleLevelDesignWorkflow.md)、规则与文件分工见 [62](62-TerrainAndEncounterDesigner.md)。

## 发布内容

- 离线浏览器编辑器提供 32 种积木、拖放、旋转、复制、缩放、撤销重做、本地草稿、图片导出与 JSON 导入导出。支持旧 v1 设计迁移到 v2；卡牌与兵种目录分别对应 48 个 CardId 和 46 个 UnitId。
- 草丛按连通区域隐藏敌军；向片外攻击时，自身及 2 米内己方草丛单位暴露 3 秒。沼泽减速 30%，预留单位免疫/加速接口。篝火是有碰撞、无血量的装饰；高山不可通行，驻军固定，地面近战不能攻击驻军。
- 增援可在开战后指定时间、指定英雄首次严格低于血量阈值、首次死亡时触发。条件延迟只登记一次，免费波次与消耗银币的敌方卡牌同时运行。
- 编辑敌方牌组、每秒银币、初始银币与上限；敌方可用小牌组循环，玩家四槽唯一手牌规则保持原状。
- `Scripts/PlayBattleLayout.ps1` 读取工坊设计，在复用战斗地图中生成地形和单位，应用部署区、波次和经济。自定义战场胜利等待敌军清除与后续定时/已触发波次，避免击败指挥官后漏掉死亡增援。
- 中英文 README、GDD 当前入口、素材来源与协作记录同步更新；新增 [项目交接](64-ProjectHandoff.md) 和根目录 `AGENTS.md`，便于新对话与协作者定位现行规则。

本版没有新增可收集卡牌，原生目录保持 46 单位、48 卡、16 种研究法术和 8 种建筑图纸。新增表现由代码几何和 SVG 构成，复用已有材质与字体，未新增第三方下载、生成图片或音频。未改写共享地图、蓝图或数据资产。

## 边界与后续

工坊目前启动独立可玩关卡，不导出 `.umap`，也未自动将设计分配到远征节点。地形为初版占位表现，高台不包含上下山路径。空间不足或满员时，波次重试最多 3 秒，再丢弃剩余数量并记录日志。复杂多条件组合、引用未来波次中的英雄实例尚未实现。

浏览器交互通过本地 HTTP 验证；`file:` 直接双击仅检查了静态依赖。实际截图和短局运行不代表长期难度、打包或硬件验收。网页模型校验比 C++ 解析器更严格；手写 JSON 的附加字段和跨类型 ID 唯一性仍有加强空间，正常工坊导出已覆盖回归。
