# v0.8.1 · 战斗精灵显示修复

日期：2026-09-23。基线：`v0.8`（`8cfd39e`）。发布分支：`main`，附注标签：`v0.8.1`，工程 `ProjectVersion=0.8.1`。

## 玩家可见变化

- **重叠显示**：角色、敌人与营地按稳定脚底位置分层，修复同平面 Masked 精灵产生的闪黑/闪烁；禁用平面精灵投影。
- **角色朝向**：行走时跟随实际主动位移，站定后面向攻击目标；攻击脉冲与死亡缩放保留镜像方向。纯上下移动沿用最近左右朝向。
- **步行动画**：24 个双足角色换用四姿势步行图；步频随主动行走距离推进，短暂停步保留进度，推挤/击退不误播普通步行；关闭战场运动模糊。

本次新增 24 张原始 RGBA 图、96 个 Sprite、24 个 Texture 与 24 个 Flipbook，共 **144 个引擎资源**，StorybookV1 累计 **919** 个。独立目录 `MovementFix` 保留新步行资源，原 D 批图集及非步行动作不覆盖。源图、参考、实际提示词、哈希、导入和审计脚本均纳入版本。

## 协作与验证

代码入口、问题原因、截图、已知边界与 UE 5.8 操作教程见 [45](45-BattlePresentationFixes.md)，完整提示词见 [46](46-MovementFixPrompts.md)，来源见 [36](36-ArtAudioSources.md)。同步更新中英文 README、任务清单、BugLog、素材规范/需求和优化协作记录；忽略 Python 工具缓存。

修复阶段 UE 5.8.1 编辑器构建成功，完整 `LittleKing` 回归 **87/87 通过**（43 无警告、44 带既有环境或预期异常警告，0 失败/未执行）。720p/1080p 各 24 张实际渲染样本覆盖左右行走、停止和前后遮挡，原五个玩家存档及 `DT_Units` 哈希不变。原始证据见 [MovementFix 验证](validation/MovementFix-Validation.json)。发布阶段只更新版本元数据与文档，复核构建、资源/提示词哈希及提交范围，不重复声称执行新的全量回归；记录见 [v0.8.1 发布验证](validation/v0.8.1-Release.json)。

这是源码与编辑器资产版本。无需手动下载或重建蓝图；更新后关闭并重新打开编辑器使用新 DLL。战斗数值和存档格式保持现状；打包与硬件测试继续后置。当前为左右两向、四姿势生成步行图，非步行动作仍沿用既有素材。

## English summary

v0.8.1 fixes flickering/dark intersections between overlapping units and camps, aligns sprite facing with voluntary movement, and replaces walking clips for 24 biped characters. Gait now follows travel distance, retains its phase across brief stops, and ignores ordinary external displacement. Battle motion blur is disabled.

The patch adds 144 Unreal assets (919 in total), original images, exact generation prompts, import/audit scripts, and documentation. The verified gameplay regression passed 87/87 tests; 720p/1080p render checks covered walking, stopping, and overlap. Combat balance and save format are unchanged. This release contains source and editor assets; packaging and hardware acceptance remain deferred.
