# v0.8.2 · 战斗平衡、远征研究与暂停

2026-09-30，UE 5.8.1。版本包含此前未发布的 Balance V1 和本轮九项远征改动，工程版本 `0.8.2`。

## 玩家可见变化

英雄和骷髅更耐打，敌军随远征深度增加生命／攻击，有限增援频率提高。敌方拥有五费骷髅法阵：范围减速、降低攻速，三秒内六次尝试召唤近战骷髅；玩家无法获得骷髅兵、射手及法阵。死灵法师献祭降至 3%。治疗波改为 120 + 英雄 6% 最大生命，仍二费、半径三百且不能救起失能英雄。

出征至少七张不同卡，默认八格容量，巨魔两格、巨像三格；固定上限的替换只允许最少必要弃牌，动态合法区间允许任何最终落入区间的组合。四槽战斗手牌继续即时补满、同卡不重复；远征内至少保留五种卡。

战斗奖励与普通市场商品只给临时佣兵。法术／建筑仅在休息节点提高本轮数值，选升级便不能同时回血。市场极低概率卖昂贵的法术书和建筑图纸，高阶书仅后期出现；带回后在图书馆消耗材料永久解锁。首版七个研究法术、攻城投石炮图纸已接入，图标沿用现有素材。

失败带回剩余金币 80% 向下取整，放弃带回 100%；已购书籍和图纸在所有结局均全额带回。战斗和部署中不能放弃，也不能暂回家园。路线／奖励／市场／休息界面可保存退出至开始页，或确认放弃后回家。

战斗暂停支持继续和退出游戏至开始／存档界面。读档重打已选关卡，保持战前英雄、卡牌、敌人和种子，不能改选岔路或刷新市场。新地图每个区域十五层，约十五站、九至十场战斗，只展示当前区域。服务操作置于长说明前，市场替换可滚动；密集节点分离，出口标签和点击位置同步。

## 兼容和验证

Run Schema 10 / Profile Schema 2 自动迁移兼容旧档，原地图和已结算金额保留，坏档不覆盖。旧五／六卡战备仍可读取，下一次出征补到七张；真实五个玩家档在开发验证期间字节未变。购买、弃牌、升级、研究与结算均验证保存失败回滚和防重复消费。

UE 5.8.1 编辑器构建成功；全量 **109/109** 自动化通过。720p／1080p 原生 UMG 检查覆盖研究、局部路线、休息、市场与暂停，20,000 次确定性市场采样验证稀有率和区域门槛。新版治疗参与的十八场实战采样另存，旧平衡采样保留历史；具体分布和局限见 [发布验证](validation/v0.8.2-Release.json)。单场采样不代表所有连战成长组合均已平衡。

本轮不用手建 Widget、补蓝图或下载素材；打包和硬件验收仍后置。试玩及调参见 [UE 5.8 教程](51-v0.8.2Guide.md)，协作者文件归属、接口和迁移细节见 [修改记录](50-v0.8.2ExpeditionChanges.md)。
