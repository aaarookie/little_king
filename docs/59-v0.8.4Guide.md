# v0.8.4 建筑试玩与调参教程

本版七种建筑的代码、卡图、战场精灵、音效和原生界面由项目提供，不需要手工创建蓝图或下载素材。本教程面向 UE 5.8 初学者，说明正式存档中的解锁流程、独立试玩和最值得检查的交互。源码与默认数值见 [协作记录](57-v0.8.4Changes.md)，图片提示词与声音来源见 [素材记录](58-v0.8.4Assets.md)。

## 启动工程

1. 关闭正在运行旧 DLL 的编辑器，打开项目的 `little_king.uproject`。提示编译模块时选择编译；也可在 Visual Studio 使用 `Development Editor / Win64` 构建 `little_king`。
2. 编辑器工具栏点击运行。正常入口仍然是开始界面，可以继续游戏、新建游戏或读取存档。
3. 已有存档不会自动获得新建筑。正式游玩需要在市场购买对应图纸，结束远征后，在家园图书馆研究，再到战备处配置牌组。

本轮没有要求更改项目设置、重新连线 HUD 蓝图或重新导入共享数据表。图纸价格与出现区域列在协作记录中；市场生成后不因读档重抽。

## 不修改存档的建筑试玩

在 Windows 打开 PowerShell，复制以下命令。引擎或工程位置不同则替换这两条绝对路径：

```powershell
& 'E:\epic\UE_5.8\Engine\Binaries\Win64\UnrealEditor.exe' 'E:\little_hero\little_king\little_king.uproject' /Game/Maps/L_BattleTest -game -V084Sandbox -windowed -ResX=1600 -ResY=900
```

这是编辑器构建中的专用试玩入口：关闭永久存档读写及远征自动保存，临时牌库包含七建筑、精灵牧师和学徒法师，银币上限 40、每秒增长 10。额外调试牌库不代表正式出征容量改变。进入后先部署全部三名英雄，再开始战斗；正常循环出牌即可看到后续建筑。

关闭试玩窗口后，按正常方式进入游戏即可使用原有存档。不需要在真实存档中输入解锁或金币命令。不要把 `-V084Sandbox` 加到平时正常运行的快捷方式里。

检查攻城车时，需要场上存在敌方建筑。可在这个隔离窗口中按 `~` 打开控制台，输入 `SpawnUnit Unit_WallCommon 1 0 400`，在敌方半场生成一段普通墙；`1` 表示敌方，后两个参数是战场 X/Y 厘米坐标。等墙建成后再观察攻城车。若落点已被占据，换一个坐标；这项调试只在当前战斗创建单位。

## 防御墙放置与修补

1. 选择墙卡，移动鼠标。轮廓表示实际墙段，箭头表示前方；禁军之墙同时显示前后 3 米范围。
2. 按 Q 或 E 每次旋转 15 度；长按连续调整。只有整个墙体都位于己方半场且不压住营地、其他建筑时才能放置。墙段可以和其他墙段部分重叠。
3. 左键确认后进入施工，血条下方显示进度。施工期间可被攻击，但尚未形成完整阻挡，也不提供反弹或光环。暂停会停止施工时间。
4. 再次选择墙卡，将中心靠近旧墙 35 厘米内，方向差在 10 度以内。预览会明确显示修补或替换；反向对齐同一墙段也算匹配，并保留旧墙朝向。
5. 同品质或低品质卡修补旧墙，恢复量等于这次新墙的最大生命，最多到旧墙上限；高品质卡则替换旧墙，重新施工。休息节点 Lv 数值升级不改变墙的品质。

施工完成时，站在墙体里的角色会被移到最近合法位置，避免卡进实体。墙体对角色形成实体阻挡；能够绕开的目标继续绕行，封闭目标需要先击破敌方墙。毁墙后路线恢复。

## 驻守与治疗

法师塔优先邀请同阵营法师英雄；没有英雄时，在法师佣兵中比较品质、费用，再随机取同档候选。单位会走到塔旁再进入。塔的状态标签显示空置、前往中或驻守者名字。驻守单位受到保护，塔破坏后恢复在外战斗；法师冷却仅在有效驻守期间加速，不改变普攻间隔。

牧师治疗站使用相同的优先顺序选择牧师。精灵牧师、牧师天使和神选牧师长都可以驻守。站点可用时，从生命低于 50% 的英雄或佣兵中邀请生命比例最低的一人，伤员前往站旁接受治疗，每次恢复牧师攻击力的 150%，满血后回归战斗。一个单位不会被两座站同时预约。没有牧师、驻守者失能或建筑被摧毁时，患者会解除预约。

所有牧师普攻只治疗受伤友军，每次为自身攻击力的 100%。精灵牧师仍然保留共沐春色，不能通过普通治疗复活失能英雄。建筑详情中的攻击力对牧师表示基础治疗数值。

## 建议的手动检查

| 检查 | 操作与预期 |
| --- | --- |
| 旋转与重叠 | 用两段墙接成直线、转角及交叉；观察预览与实体是否一致 |
| 封闭与破墙 | 用多段墙围住可攻击目标；敌人不能穿墙，墙破后可以进入 |
| 修补与替换 | 用普通墙修补高品质墙，再用高品质墙替换普通墙；检查预览、血量、施工时间和费用 |
| 反弹 | 让多个敌人打史诗墙；不同敌人独立触发，单个敌人不会在半秒内连续受到反弹 |
| 禁军之墙 | 在两个同向或相反方向的墙附近布兵，观察增攻及恢复区域，破墙后效果解除 |
| 攻城车 | 观察其缓慢接近建筑、每三秒攻击；墙受目标最大生命 20% 伤害，无建筑时停止 |
| 法师塔 | 部署法师后建塔，观察走入和驻守标签、技能频率、塔破后的释放 |
| 治疗站 | 部署精灵牧师和受伤佣兵，观察最低血量比例的目标接受预约、前往、治满归队 |
| 暂停与声音 | 暂停应停止施工、技能、治疗；恢复后继续；试听建造、修补、破墙、反弹、攻城、驻守及治疗声音 |

## 调整数值与扩展

在内容浏览器中打开 `DT_Units`，找到目标行后可调整生命、移动速度、攻击间隔等数值。新建筑若没有对应行，仍会使用 `LKV084Content.cpp` 的默认值；添加同名行后，合法数值会合并到私有运行时配置。职业、品质和建筑行为属于代码登记的身份，避免旧表误改玩法。

新增墙参数为 `ConstructionSeconds`、`WallLength`、`WallThickness`、`ReflectDamage`、`WallAuraRange`，单位分别是秒、厘米、厘米、伤害、厘米。例：3 米墙长写 300。Q/E 朝向属于每次放置的命令，不写回数据表。攻城车的 10%/20% 规则在建筑行为中定义，不由普通攻击力覆盖。

音效默认从 `LKV084Art` 注册到 `SoundMap`。保留原有的显式静音和自定义覆盖。素材已经导入；只有更换源文件时才需要运行对应导入脚本，步骤和资源路径见素材记录。
