# D5 · 安全节点存档 UE 5.8 教程（验证为主）

适用版本：UE 5.8.1，D5。**C++ 存档/恢复与原生界面已完成并通过 32/32 自动化**；本批次没有必须由你制作的蓝图。请按第 3 节做 PIE 验收（覆盖"路线/奖励界面退出后继续"与"战斗中退出恢复"两条主路径）。

## 1. 规则（已实现）

- **自动保存点**（写盘失败只记日志，不中断）：新远征开始、每场胜利结算、领取/跳过奖励后、选择节点后（进入战斗前=恢复点）
- **固定存档槽**：`LittleKing_Run`（本地 Saved/SaveGames）
- **冷启动恢复**（重开游戏/编辑器后直接 Play）：
  - 上次在**战斗中退出** → 回到该房开战前：同遭遇/种子/尝试，重新部署开战（弹道/技能等临时状态不保留）
  - 上次在**奖励/路线选择中退出** → 进入选择界面：先领/跳过待选奖励，再选下一排节点
  - 上次**通关/失败** → 显示远征总结（战斗数/胜负/击杀），可"开始新远征"
- **数据校验**：文件版本/结构版本超出支持范围、数值非法、引用缺失的存档**明确拒绝载入且保留原档**；同一胜利窗口的奖励批次标记随档保存——重复读档不会复制奖励
- **身份特性补全**（BUG-017）：载入后按当前代码配置补回缺失的**身份特性**（法师全场施法 `Trait_MageSpellReach`、骑士嘲讽光环 `Trait_KnightTauntAura`、盾卫 `Taunt`），并同步到待开战上下文；只加不删，房间间用 `RunHeroTrait` 临时增删的其他特性仍只在本次会话内生效。日志：`[Run] 身份特性补全：Hero_Mage + Trait_MageSpellReach`
- 只有明确动作（开始新远征/从头开始）才覆盖旧档

## 2. 界面

| 时机 | 表现 |
|---|---|
| 恢复=选择中 | 自动弹奖励面板（若有待领）→ 领完弹节点选择面板 |
| 恢复=终态 | 原生"远征总结"面板：标题 + 摘要 + [开始新远征] |
| 正常流程 | 与 D3/D4 完全一致（无感知） |

## 3. PIE 验收脚本

**A. 路线/奖励界面退出后继续**
1. Play → 打通第 1 战 → 领取/跳过奖励后停在节点选择面板
2. 直接关闭 PIE（相当于退出游戏）
3. 再次 Play（新会话）→ 应自动恢复：弹出节点选择面板（第 2 排两个节点），不重新打第 1 战
4. 选战斗继续 → 正常部署开战；日志出现 `[Run] 已从存档恢复远征` / `恢复选择流程`

**B. 战斗中退出恢复**
1. Play → 打到第 2 战战斗中途（敌方已出怪）→ 关闭 PIE
2. 再次 Play → 应回到第 2 战部署界面（日志 `恢复战斗：第 2 战`），重新部署开战；敌我状态全新，英雄继承恢复后血量
3. 打完第 2 战胜利（领奖）→ 继续走完通关

**C. 通关/失败摘要与防重**
1. 完整通关一次 → 关闭 PIE → 再 Play → 显示"远征总结（远征通关！共 4 场战斗…）"→ 点[开始新远征] → 新远征房 1 满血开始
2. 失败一次重复同样操作 → 摘要显示"远征失败…"
3. 防重抽查：恢复"选择中"状态后连开两次 PIE，奖励领取只生效一次（卡不翻倍，日志无第二次 `领取奖励`）

**D. 损坏档保护（可选）**
在 `%LOCALAPPDATA%\LittleKing\Saved\SaveGames\LittleKing_Run.sav` 用记事本改坏几个字符 → Play → 日志 `存档校验失败…（保留原档）`，游戏按新远征开始，不会把坏档当正常档读入。

## 4. 常见问题

| 现象 | 处理 |
|---|---|
| Play 后直接开了新远征（没恢复） | 确认是"退出后重新 Play"而非连续重载：恢复只在进程冷启动（新 GameInstance）时读取 |
| 恢复后奖励面板/节点面板没弹 | 等 HUD 出现后若仍无，控制台看 `[RunUI]` 日志；可手动 `RefreshNodeSelectPanel`（蓝图/命令） |
| 战斗中退出后回来要从头打这一房 | 预期：恢复到"该房开战前"，弹道/技能/双方状态不保留，会重新开战 |
| 想清除存档重来 | 删除 Saved 下 SaveGames/LittleKing_Run.sav，或先通关/失败后点"开始新远征"（覆盖） |
| 法师在场却提示"没有全场施法特性"（BUG-017） | 先看部署日志 `[Run] Hero_Mage 应用永久特性：…`：显示 `无` = 该远征快照缺身份特性，载入时已由 `RestoreHeroIdentityTraits` 自动补回（日志 `身份特性补全`），下次恢复即正常；若显示 `Trait_MageSpellReach` 却仍被拒，看 `[Spell] … 施法被拒绝：存活英雄 …` 一行定位 |
