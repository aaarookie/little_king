## 一、项目简介（先了解我们在做什么）

**《小小国王》(Little King)** 是一款个人开发的 **UE5.8（虚幻引擎 5.8）2D 自动战斗 + Roguelike 卡牌**游戏，当前处于"战斗原型"阶段（Sprint 0~5 已完成），PC 平台。

一句话玩法：**你扮演一位不出征的小小国王，指挥英雄与军团替你打赢一场场自动战斗，再走进随机地牢获得新卡牌，回家园强化阵容**——三种模式循环（类《皇室战争》的战场 × 类《杀戮尖塔》的卡组 × 类《地牢爬行》的地牢 × 家园经营 Meta）。

### 核心体验循环
```
家园（选卡组/强化）→ 地牢探险（战斗+事件，获得新卡）→ 战场对战（自动战斗，验证卡组）
        ↑___________________________________________|
```

## 二、世界观与美术气质

- **基调**：温暖童话的王国。战场发生在王国各处（庭院/荒野/地牢），不靠黑暗血腥，靠**繁复华丽 + 幽光**营造氛围（见风格指南：宫崎骏式唯美 × 极繁装饰，翡翠绿/琥珀金/灰玫瑰主色板）。
- **我方角色**：小小国王坐镇王城不出征；**英雄代王上阵**（骑士/法师/游侠）；士兵是王国的仆从与卫兵。
- **敌方角色（重要）**：敌人**不是固定单一势力**——这个世界观里有多种族共存的广阔世界（人类、精灵、矮人、亡灵骷髅、哥布林、巨魔、龙等），任何种族都可能作为敌人出现，**具体敌军构成以后续剧情与章节设定为准**（例如：某章节对抗人类叛军/邻国军团，某章节深入哥布林巢穴，地牢里则是亡灵与野生魔物）。制作时请先与我确认当前章节需要哪些种族，**不要假设只有骷髅**。
- **风格红线（对所有种族敌人同样适用）**：延续"华丽童话"气质——骷髅参考"生锈华丽盔甲 + 幽蓝魂火"（可爱但不吓人）；其他种族同样**回避血腥恐怖**（哥布林是滑稽狡黠的、巨魔是憨厚笨重的、龙是威严华丽的），整体仍是吉卜力式暖童话，只是多一层"反派感"。
- **视角**：战场为 2.5D 斜俯视（皇室战争/元气骑士式，画面看得到角色的脸和上半身），逻辑上是平面坐标。**角色图请出"正面/3/4 视角的站姿"**，不要出"俯视头顶"图。

## 五、2D 角色动画：现状与升级路线（重点）

### 5.1 现状（Sprint 5 起）：程序化动画，单帧精灵即可
战场上单位的所有"动感"由引擎代码完成，**不需要作者出任何动画帧**：

| 动作 | 实现方式（引擎内，已上线） |
|---|---|
| 移动 | 平面滑行 + 朝向翻转 |
| 攻击 | 0.15s 前摇停顿（站定蓄力感）+ 命中瞬间缩放脉冲 1.15→1.0 |
| 受击 | 精灵闪白 0.08s + 命中停顿 |
| 死亡 | 0.35s 缩小+淡出 |
| 远程 | 弹道飞矢（引擎对象池） |
| 技能 | 英雄施法由 C++ 触发，特效待 P0 资产 |

→ **P0 阶段你只交付"一张站姿单帧"**，这是当前所有单位资产的最短路径。

### 5.2 中期升级：逐帧 Sprite Sheet（内容扩充期实施）
当"单帧+程序动画"不够看时，按下面规格做逐帧动画。**引擎接入（Paper2D Flipbook / 状态映射）属于程序后续工作**，你**先按命名与网格规范交付帧图**即可，双方按表对齐。

**帧规格（2.5D 单朝向方案——默认推荐，成本最低）**：
- 单朝向（正面 3/4）即可：**左右移动用水平镜像**，无需画 4 向（省 3/4 工作量）
- 每动作帧数与尺寸：

| 动作 | 帧数 | 建议内容 | 状态机对应 |
|---|---|---|---|
| Idle 待机 | 2~4 帧循环 | 呼吸/飘动（英雄 4 帧，小兵 2 帧） | 待机/移动停下 |
| Walk 移动 | 4~6 帧循环 | 步伐循环 | 移动 |
| Attack 攻击 | 4~6 帧（一次性） | 蓄力→挥击/拉弓放箭 | 攻击（配引擎 0.15s 前摇节奏） |
| Hurt 受击 | 2~3 帧（可选） | 后仰 | 受击闪白（可选叠加） |
| Death 死亡 | 3~4 帧（可选） | 倒下 | 死亡（引擎默认缩放淡出，可二选一） |

**网格与命名规范（重要，双方必须一致）**：
```
单张 Sprite Sheet = 一个动作（行优先，帧从左到右、从上到下，等尺寸等间距）
命名：<单位ID>_<动作>_<帧数>f.png
示例：Hero_Knight_Attack_6f.png（6 帧攻击）、Unit_Swordsman_Walk_6f.png
帧尺寸：与 P0 单帧同画布（512×512 内角色占 70~80%）；动画不超画布边界
锚点：脚底中心 = 画面水平中心、底边（我们按脚底对齐战场平面）
```
- 工具建议：像素风用 **Aseprite**（便宜/专业）；手绘风用 **Krita/PS + 帧动画**；两者都导出透明 PNG 序列或整张 Sheet 均可。
- **出图渠道**（若你用 AI 生成动画帧）：逐帧一致性目前仍是 AI 短板——建议用"参考图 + 姿态描述"逐帧生成再统一描线，或**放弃逐帧、加钱买"程序动画"表现**（我们默认路线）。

### 5.3 长线（暂缓）：骨骼动画
Spine/DragonBones/Live2D 适合**立绘动态化/剧情演出**（英雄对话、结算 MVP），需要第三方插件与授权，**原型期明确不做**。若将来做，优先 Spine（UE 生态最成熟），届时再出骨骼/插槽规范。

## 九、授权与质量红线（必读）

1. **必须可商用**：CC0 / CC-BY（署名按作者要求）/ 完全自制 / AI 工具按其平台商用条款（ChatGPT/即梦等个人商用请自查最新条款并**注明生成工具**）。**禁止**任何来源不明/版权素材（游戏/动画截图改图、无授权素材站文件）。
2. **风格一致性**：每张图对照 07 风格锚点自查（色板/笔触/装饰度）；同一角色不同图必须共用三要素（发型发色/服装主色/标志物）。
3. **负面清单**（07 §⑤）：no text/no watermark/single character/不写实不 3D 不恐怖——AI 出图时原样粘贴。
4. **交付自查**：透明底（或注明纯绿/纯白底）· 画布规范达标 · 命名规范 · 小尺寸预览可读（缩到 64px 还能认出是谁）。
5. 收到后我们会**在引擎里逐张验收**（导入→战场 PIE 截图回传），不合适会说明具体差异点，请按反馈迭代。
