## 当前可玩的系统

- UE 5.8 C++ / Paper2D / GAS / 原生 UMG，单机 PvE 自动战斗。D0–D5 地牢、H0–H5 家园已完成开发；家园七建筑、最多八个存档、开始菜单、远征存档、研究与暂停均已接入。
- 远征有五个固定地理区域，通常经过四区；每个区域走约十五个节点，九至十场战斗。只展示当前局部地图。英雄局内生命归零失能，战后按神像等级恢复最大生命的 40/60/80/100%。
- 出征至少七种卡。默认部队容量八格，巨魔两格、巨像三格；抽到时仍只是一张手牌。战斗四槽始终补满且无重复，至少保留五种牌。动态容量区间和最少必要弃牌已有算法，勿退回简单“随便丢一张”。
- 玩家不能获得骷髅兵、骷髅射手、骷髅法阵。远征只新增临时佣兵；法术/建筑由市场罕见研究材料带回家解锁，只能在休息节点升级。失败带回金币80%，放弃全额，购买的研究材料总是带回。
- 暂停可退至开始菜单，读档重试已选择的战斗，不能刷新分支、市场和敌阵；战斗/部署中不能放弃，远征中不允许临时回家。
- 必须部署全部三英雄才开战，没有部署倒计时。营地有体积且不可攻击；英雄活动不限营地半径（后续修订规则），手动移动打断战斗。嘲讽高于集火，但免疫嘲讽的特定单位保留例外。仅火球产生小震动。
- 当前 46 单位、48 卡、16 种研究法术、8 种建筑图纸。所有牧师普通攻击仅治疗友军；墙体、攻城车、驻守塔与治疗站已交付。身份/行为由 C++ 兜底，数据表主要用于数值和表现，运行时修改私有副本。

## 战场工坊与运行接口

| 部分 | 入口与约定 |
| --- | --- |
| 网页 | `Tools/BattleDesigner/index.html`，无依赖安装；模型/交互为 `model.js` / `app.js` |
| 内容目录 | `catalog.js` 是48张 CardId，`units.js` 是46种 UnitId；两者不可互换 |
| 设计格式 | `little-king.battle-layout` v2；v1可迁移，导出普通“设计 JSON”供试玩使用 |
| C++ 导入 | `LKBattleLayout.*` 解析；`ALKBattleGameMode_Layout.cpp` 应用布局与独立入口 |
| 地形规则 | `ALKBattleTerrain.*`，连接寻路、伤害资格、视野、出生和部署检查 |
| 增援 | `ALKOpponentBrain.*`；指定对象原始ID以 Actor Tag 绑定；不按同名兵种猜实例 |
| 敌方经济 | `ULKDeckState::InitEnemyDeck` 支持单卡循环；免费增援与付费卡牌并行 |
| 试玩 | 根目录运行 `Scripts/PlayBattleLayout.ps1`；`-Layout` 指定JSON，`-AutoStart`为测试自动部署 |

设计以左上角为原点，单位米，位置为中心：`UE.X=(height/2-y)*100`，`UE.Y=(x-width/2)*100`，`UE.Yaw=90+rotation`。默认40×24米。整个旋转轮廓参与边界校验，不能只验中心。

草丛：同一连通片内互见；攻击片外目标时，自身及2米内己方草丛单位暴露3秒。黑云隐藏独立管理，不能被草丛暴露清掉。沼泽移速乘0.7，重叠不叠乘；`SetSwampMovementMultiplier` 可预留免疫/加速。篝火无血条且阻挡。高山不可上下，驻军不移动/不受位移，地面近战无法伤害高台单位，远程和法术可用。

波次的 `Time` 对定时波次是开战后秒数，对条件波次是触发后延迟。阈值严格小于，首次事件只登记一次。默认每阵营最多20战斗单位，波次缺位置/满员最多重试3秒。自定义关卡胜利等待清敌与未来定时/已触发条件波次；无法再触发的条件不能使战斗永久挂起。

当前独立试玩不写入远征存档，尚未自动分配到远征节点；没有宣称生成 `.umap`。水域、道路、花草仅装饰，树木/岩石阻挡；敌方出现区和文字只是设计标注。几何/SVG为初版素材。
