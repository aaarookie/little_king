## 协作约定

- 保留协作者改动与玩家存档。共享数据资产只作源数据，运行时调参使用私有副本。
- 内置身份、技能和行为由 C++ 默认值保证；数据表调节数值与表现。UnitId 与 CardId 分开，注册内容变更时同步工坊目录。
- 当前规则按主题更新，行为/接口变更在对应阶段记录验证。文档与源码冲突时核对实现，不依据历史设计恢复旧规则。
- 先用 `rg --files` 定位文件；大型 JSON 仅读摘要及所需字段。`Saved` 日志可能仅存在本机，带警告通过不等于零警告。
- 文档整理只做引用、差异及现有证据检查；行为变更才执行相应测试，必要时全量。不得把历史报告写成此次重测结果。
- 发布请求包含版本元数据、记录、提交、标签、推送与远程核验。Git 每条联网命令使用 `-c http.proxy=http://127.0.0.1:18081`；PowerShell 中含 `^{}` 的 Git ref 必须整体引用。
- 测试夹具避免 `TArray.Add(A[0])` 自引用；几何修复需核查放置、移动、到达的真实流程；新增内容时同步展示夹具与目录。
- 用户重视统一美术与协作修改记录。旧对话仅用于查证，当前工作不受历史工具分工限制。
