# 小小国王 · Little King

[简体中文](README.md) | [English](README.en.md)

UE 5.8 · C++ / Paper2D / GAS / UMG · 单机 PvE 自动战斗原型。当前版本 **v0.8.3**，工程版本 `0.8.3`。

在家园配置三名英雄与牌组，从大门出征。战斗前布置全部英雄，战斗中指挥营地、循环出牌；在随机路线中选择战斗、市场或休息，带回金币及研究材料发展家园。

## v0.8.3：研究法术与天使增援

- 新增九张需研究解锁的法术：冰冻、四档圣玛丽亚增援、黑云、雷电、飓风和神圣祝福。通过市场法术书、回家研究、战备编组的既有流程获得；新增内容不会自动解锁。
- 十一种天使数值配置共享五种角色美术，只由法术召唤，不进入手牌或佣兵奖励。牧师普攻治疗受伤友军，不能救起失能英雄。
- 黑云隐藏双方区域内单位；雷电只打敌方非英雄，第二击重新选目标；飓风强制推动双方可移动角色，营地和建筑固定。
- 神圣祝福治疗己方全场，施放后 150 秒内不会再次抽取；手牌保持补满且不重复。暂停停止冷却，换房重置。仍只有火球产生小震动。
- 包含五套各 16 姿态的透明动画图集、九张法术卡插画、六条原创施法音效。完整原图、生成提示词、声音合成参数与导入脚本随仓库提供。

## v0.8.2 基础规则：战斗平衡、远征研究与暂停

- 首版平衡提高双方英雄及骷髅生命，敌军生命／攻击随远征深度提高；有限增援更密集，加入敌方专属骷髅法阵。死灵献祭改为 3%。骷髅兵、骷髅射手和骷髅法阵不能由玩家获得。
- 治疗波为范围治疗 120，英雄额外恢复 6% 最大生命；费用 2、半径 300。普通治疗不能战内救起失能英雄。
- 出征至少七种不同卡，默认部队容量八格；巨魔占两格、巨像占三格，四槽战斗手牌每卡仍只显示一张。固定上限只允许最少必要弃牌，动态合法区间允许所有落入区间的替换方案。战内至少保留五种卡，四槽始终补满且不重复。
- 战斗奖励／市场只新增临时佣兵。法术、建筑只在休息节点升级，每级数值乘 1.1；本次休息在回血和升级间二选一。
- 市场极低概率出售昂贵的法术书／建筑图纸，高阶书只在后段出现。结束远征后，在图书馆消耗材料永久解锁；v0.8.2 提供七个研究法术及攻城投石炮图纸，v0.8.3 将研究法术扩至十六个。
- 失败带回剩余金币的 80%（向下取整），放弃带回 100%；已购买材料在任何结局均全数带回。战斗／部署期间不能放弃。
- 战斗点击暂停或按 Esc，可继续或“退出游戏”至开始界面；继续存档重打已选战斗，保留战前英雄、卡牌、敌阵及种子，不能改选岔路口或刷新市场。
- 每个区域约十五层路线，实际走过约十五个节点、九至十场战斗。远征只展示当前区域；进入下一地区后才查看其地图。远征中回家须明确放弃。

## 当前玩法

家园有圣玛丽亚神像、图书馆、大门、英雄之家、金库、军营和战备处七座建筑。神像使战后恢复为 40/60/80/100% 最大生命；金库银币上限为 5/7/9/11/13、产速每级提高基础值的 10%，出征金币携带上限为 100/150/200/250/300。收益不受携带上限限制，加成在出征时冻结。

五个区域具有固定地理边界、入口及出口，内部节点和有向连接每轮生成并保存。通常经过四个区域，每层选择一个节点。普通战一名敌方英雄、精英战多名英雄、首领战含 Boss 及英雄；敌人每房满血重建。

英雄开战前必须全部部署且不限时。营地有实体体积、不可攻击；点营地后点任意可达地点下达移动指令，移动期间停止自动攻击，到达或卡住超时后恢复。法师提供全场施法，失能后只能在己方半场放法术；骑士赋予附近己方近战佣兵嘲讽，优先级高于集火。战斗实体拥有头顶血条，营地无血条；攻击建筑部署时显示射程，半场黄色中线常驻。

角色／建筑分普通、优秀、稀有、史诗、传说；法术分十四个阶位。当前目录有 39 个单位、41 张注册卡，其中十一种单位只能召唤、三张卡敌方专属、十四张卡为远征临时佣兵；其他为初始或研究解锁内容。图鉴见 [19](docs/19-ContentCatalog.md)，技能和新卡接口见 [32](docs/32-CharacterQualityAndBalance.md) / [34](docs/34-CardDevelopmentInterfaces.md) / [35](docs/35-TrollAndSiegeCards.md)。

## 构建与试玩

1. 关闭此项目的编辑器，用 UE 5.8 构建 `little_kingEditor / Win64 / Development`：

   ```powershell
   $engineRoot = 'E:\epic\UE_5.8'
   $projectPath = (Resolve-Path '.\little_king.uproject').Path
   & "$engineRoot\Engine\Build\BatchFiles\Build.bat" little_kingEditor Win64 Development "-Project=$projectPath" -WaitMutex -NoHotReloadFromIDE
   ```

2. 打开 `little_king.uproject`，点击 Play。默认进入 `L_StartMenu`，可继续、新建或读取／删除最多八个独立档；设置暂为接口。
3. 在家园战备处保存三名英雄和至少七张卡，到大门设置金币并出发。进行中的存档会直接恢复远征。
4. 部署英雄后开战；点卡牌再点合法战场落点。胜利后选奖励、沿路线前进，市场购物、休息回血或升级。
5. 通关／失败返回家园结算；要中途回家，须在非战斗节点确认放弃；暂时离开则退出至开始界面。

控制台 `show me the money` 默认增加 100 永久金币，`show me the money 500` 指定数量。界面、地图、美术、声音和中文字体已包含，无须补建蓝图或下载素材。源码调整后重新构建即可；基础操作见 [51](docs/51-v0.8.2Guide.md)，九法术隔离试玩、冷却界面预览与试听见 [55](docs/55-v0.8.3Guide.md)。

## 协作与素材

`Source/little_king` 为代码及原生界面，`Content` 为地图／蓝图／数据资产，`Scripts` 为资产同步与审计工具，`docs` 为设计／协作记录／教程／验证，`ArtSource/StorybookV1` 归档原图、声音、提示词与许可，`Saved` 是不提交的本地日志及玩家档。

内置单位身份、技能和行为由 C++ 保证，数据表用于数值及表现调节；自定义 UnitId 仍支持。v0.8.2 修改了单位／遭遇表、GameData 和治疗波资产；v0.8.3 通过原生内容和私有副本扩展，新增资源集中于 `Art/StorybookV1/V083`。本轮没有写回共享地图、蓝图和数据资产，协作者文件清单见 [53](docs/53-v0.8.3Changes.md)。
