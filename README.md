# 小小国王 · Little King

UE 5.8 · C++ / Paper2D / GAS / UMG · 单机 PvE 自动战斗原型。

玩家部署三名英雄，以营地为支点指挥英雄、循环出牌，保护己方英雄并击败敌方英雄。当前可运行范围是单场战斗，下一阶段进入地牢开发；详细任务安排已完成。

## 当前进度：Sprint 5 修订

本轮把规则修复、营地指挥、满手循环、英雄特性、建筑射程预览与半场黄线一起纳入 Sprint 5。用户已做数次试玩并反馈效果不错；编译和定向逻辑验证见变更记录。**Sprint 6 已删除并跳过，直接进入阶段 2 地牢**；音效、表现素材、打包和硬件测试后置。

- 开战前必须部署骑士、法师、游侠；部署不限时。
- 每个英雄有固定实体营地，移动受营地半径约束。点击己方营地，再点击范围内目的地；右键取消。移动期间暂停攻击，到达后恢复。
- 手牌固定 4 槽且始终补满，牌组按 CardId 去重。开局洗牌一次；成功出牌后队首补入原槽，打出的牌排到队尾，按序过牌。默认七种，最低五种。
- 法师的全场施法特性存在时可全场落点；失去特性后仍可在己方半场施法。骑士让附近己方近战佣兵获得嘲讽，嘲讽高于集火。游侠暂不配置新特性。
- 每个战斗单位都有头顶简易血条，营地无血条。只有火球卡和当前法师火球技能释放时产生小震动。
- 放置箭塔等攻击建筑时显示占地圈和基础射程圈；黄色半场中线独立显示，不依赖调试开关。
- 包含实际伤害/治疗统计、批量胜负判定、实体绕路、连续路径弹道命中与对象池。

## 运行

1. 关闭编辑器，用 UE 5.8 构建 `little_kingEditor / Win64 / Development`。
2. 打开 `little_king.uproject`，按[迁移教程](docs/16-Sprint5MigrationTutorial.md)更新旧 HUD、检查资产配置。
3. 打开 `Content/Maps/L_BattleTest`，确认 GameMode 为 `BP_ALKBattleGameMode`，点击 Play。
4. 点英雄按钮后在己方半场放置，全部就位后点击开始；战斗中点击卡牌再点击战场。
