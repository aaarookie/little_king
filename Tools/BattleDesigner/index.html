从想法到可试玩地图

你的战场，三步搭好

  1. 摆积木，确定空间

    左边选择地形、障碍、单位或建筑，拖进画布。左侧是玩家半场，右侧是敌方半场；位置与尺寸都以米记录。至少放置一名开局敌方英雄或首领。

  2. 设置敌军与规则

    用右侧三个页签编辑布局、一次性增援和敌方银币牌组。敌方区域和文字仅作标注；草地、道路、水域、花丛只有静态装饰效果，树木和岩石会阻挡移动。

  3. 下载 JSON，进入游戏试玩

    JSON 是可再次编辑的完整设计。图片只用于讨论，不能替代 JSON。UE 5.8 项目编译完成后，在项目目录打开 PowerShell，执行下方脚本；浏览器不会直接启动引擎。

    .\Scripts\PlayBattleLayout.ps1 -Layout "C:\路径\我的战场.json"

    直接运行 .\Scripts\PlayBattleLayout.ps1 会打开高地伏击示例。默认 UE 路径为 E:\epic\UE_5.8，可用 -EngineRoot 指定其他安装位置。普通试玩先部署英雄；-AutoStart 供自动开战测试使用。此入口运行独立战场，不创建远征或家园存档。

纸上草图也可以

正上方拍照，写清起点、敌人、障碍、路径与特殊规则；用编号把密集说明写在旁边。标一条参照长度（例如“这面墙 3 米”），字迹尽量清楚。照片中不明确的地方会先核对，再转成同样的模块化布局。

两种敌军来源

右侧“增援波次”可指定开战时间，或指定地图英雄首次低于某生命百分比、首次死亡后的延迟；每条波次只触发一次。设定兵种、数量、分散半径后，可以点击“在地图选落点”。条件英雄必须开局出现且数量为 1，删英雄前请先改动引用它的波次。

“敌方牌组”独立设置可用卡牌、初始银币、每秒银币和上限。两种来源可以同时开启，事件增援不消耗银币。旧版 JSON 和草稿会自动迁移，默认关闭敌方主动出牌，保留原来地图对象的出现时间。

四种战场地形

草丛使其中单位对外隐身，同一连通片内可见；向外攻击会暴露自身与 2 米内友方草丛单位 3 秒。沼泽减速 30%。军营篝火为不可攻击实体装饰，需绕行。高山为无法上下攀爬的固定高台，放置在上方的驻军只能被远程与法术攻击。
